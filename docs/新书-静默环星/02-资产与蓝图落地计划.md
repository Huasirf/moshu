| category | 必填字段 |
|---|---|
| equipment | tier / slot / attrReq（F–D 逐项）/ attrTotalReq（C+）/ baseStats / integrity / endurance / affixes / trigger / cooldown / cost / source / repair / binding / marketPrice / unusable |
| card | cardType / tier / uses / replenishable / effect / targets / cooldown / slotCost / carryLimit / condition / marketPrice |
| material | materialType / grade / source / use / marketPrice |
| intel | intelType / holder / value / risk |
| tool | toolType / function / charges / weight / failureRate |
| consumable | consumableType / effect / units / duration |
| special | specialType / boundTo / slots / repairStage / permissions（返界锚）/ repairPart（修复件） |

### 其他类型

| entity_type | 关键字段 |
|---|---|
| skill | series（九系）/ tier / tierReq / attrReq / brainReq / slotReq / effect / cost / cooldown / sideEffect / growth / source / panelText / owner / forEnemy / obtained |
| location | region / access / danger / hazards / resources / storyFunction / mapNodes / firstEnterChapter |
| faction | scope / type / stance / base / leadership / resources / relations / givesProtagonist / takesFromProtagonist / entry / roster |
| secret | level / holders / revealChapter / consequence / linkedAssets |
| number | value / unit / scope / source / note |

### 硬规则

- F/E/D 装备：`attrReq` 逐项写死，合计等于 50/300/700 只是设计预算；穿戴逐项校验。
- 民用三件套：`tier = 民用（总属性门槛型）`，`attrTotalReq = 0`，全书限 3 件。
- 每件装备至少写一个 `unusable` 场景。
- 材料/情报/工具一律不发属性点。
- 候选池资产 `firstChapter = 0`，`notes` 标「候选池·未定章」。

## 十、验收清单

- 资产字段完整性（按 category 必填项）
- `assetRefs` 指向的 id 全部存在
- 蓝图场景数 2–3、章字数 1900–2200、字数偏差 ≤10%
- 关卡章标题命中卡名
- `speechStyle` / `imagePrompt` 非空率 100%
- 禁用词扫描：老茧、薄茧、机油渍、喜欢算账、口头禅
- 入口章按「投放厅刷身份卡开门→投候室→投放台激活」三拍；不出现灰门、灰格、灰色通道、第八色或试炼卡变色
- 首试不结算属性点/试炼卡，不提前揭示「投放档位：黑」；无临时观测档、无回执、无封存
- 首试返程由系统回收，坠饰不触发通道；第一次私人远征前锚不启动
- 视角保持第三人称限知；「系统摘录」插页每卷不超过 2 次，只写面板字段/日志/动作/对话，不得借此呈现官方对首试的调查
- 入场剥离的背包、水壶、工具不得在场内无来源出现；旧水壶/旧背包必须在场内捡到
- 白卡、仓库月租、民用装备与医疗包价格不得超出主角存款（本地黑市白卡四千、仓库月租一千押一付一）
- 资产 `firstChapter` 与蓝图首次引用章一致
- 材料/情报类无属性点字段
- **探索场章不得出现其他参赛者、抢节点、抢闸门**；节点只能由系统守卫或环境构成
- **对抗场（采集/竞速/战斗/防御/生存/混合）必须有异族参赛者**；异族不出台词，系统只给「非本文明参赛者」标记，不给翻译与保护
- 生存场章必须写清存活时限、生存目标与提前退出扣点 30；不得写成守点防御场
- **回归落点**：正文不得出现“只回原点”“方圆二十公里随机”“预设安全点”“登记坐标”；统一写十公里环带随机落点，入场前不需也无法登记；首试返程必须写系统回收投放阵列
- **官方调查线**：官方从未知情，不得出现复查、约谈、重点观察、档案复核岗追查男主；也不得出现封存、回执、临时观测档、内部日志调阅

# 回归与激活规则修订 v3

> 项目：开局误入高阶试炼（静默环星）
> 更新时间：2026-11-01
> 适用范围：规则库 R-13-1 至 R-13-9、第一卷第30—48章及后续所有普通试炼章节

## 一、最终规则

### 1. 个人安全点

每名参与者登记一个个人安全点。系统只保存回归坐标，不向官方、公会、队友或其他参与者公开。安全点是参与者的私人回归坐标，不等同于官方试炼厅。

每个蓝星自然月只能更改一次，试炼中不能更改。商陆野第一次异常试炼前登记的是城中出租屋；第35章租下城郊工业仓库后，当月不能再次改点，所以仓库先作为装备、储备和研究地点。

### 2. 结束后的回归选择

普通试炼成功、主动退出、系统强制回收或失败但未死亡时，参与者可以二选一：

- 回自己的个人安全点；
- 回到本次试炼卡激活点周边十公里内由系统选定的安全位置。

第二个位置避开战斗、火灾、坍塌、深水和明显监控，但不是固定坐标，参与者不能提前指定。死亡不会触发回归。队伍可以共同选择激活点周边安全位置，也可以各自回个人安全点。

### 3. 激活地点与激活时长

试炼卡可以在现实世界任何地点激活。完整激活约三秒，成功后才生成本次试炼的激活点记录。

三秒内遭到攻击、束缚、强行移动、失去意识或被迫改变位置，均视为激活失败。失败不消耗试炼卡、不占用试炼次数、不生成激活点。

官方保密进入点的作用是发卡、登记、隐藏信息和提供基础说明。它是安全的保密地点，不是唯一激活地点，也不是默认回归点。

### 4. 返界锚与静默回响考验

返界锚完成一次“现实—试炼—现实”的完整往返后，永久扣除当前任意属性一点；普通试炼结束的常规回归不重复扣除返界锚代价。

每90天触发一次静默回响考验，主要依靠心识通过。失败扣当前任意属性一点，并留下7天静默回响。返界锚的往返代价和静默回响考验的失败代价是两条独立规则。

第一次异常试炼的系统自动回收直接落到个人安全点，不显示官方接应、不建立官方回归记录，也不计入返界锚完整往返，因此不扣返界锚永久代价。

## 二、第一卷连续性修订

| 章节 | 新定位 | 必须兑现的规则 |
|---:|---|---|
| 30 | 异常回收 | 系统直接把男主送到个人安全点；无官方接应和官方回归记录 |
| 31 | 回到安全点 | 男主独自检查出租屋、清点收获、观看现实新闻，认识到蓝星也可能被入侵，立下变强目标 |
| 32 | 没有官方记录 | 通过现实核查说明官方保密进入点只是发卡和登记地点 |
| 35 | 仓库与安全点 | 工业仓库用于储备和研究；月度限额使出租屋继续担任安全点 |
| 39 | 白卡缺口 | 计划普通试炼时区分个人安全点与激活点十公里回归范围 |
| 40 | 返界锚的代价 | 把返界锚扣属性和静默回响考验失败扣属性分开解释 |
| 47 | 出发前夜 | 官方点只负责领取和登记，男主准备在其他可控位置激活 |
| 48 | 黑色试炼：进入 | 离开官方点，在现实可控位置完成三秒激活，生成新的激活点 |

## 三、写作注意

- 第31章不安排官方交流，不安排官方盘问，不安排官方人员追到出租屋。
- “官方保密进入点”“试炼卡激活点”“个人安全点”“激活点十公里回归位置”四个词必须分开使用。
- 普通试炼结束时，回归选择应成为角色决策，而不是系统默认把人送回官方地点。
- 对二级文明毁灭只给出“外部文明入侵、自救协议失效、双方重创或同归于尽”的片段性真相，完整解释留到后续卷。

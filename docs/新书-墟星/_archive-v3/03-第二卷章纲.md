# 《全民求生：极点》第二卷章纲：一道门

> 时间：第 10–18 月（中纬区，南北约 4,000km）
> 章数：81 章，按 3000 字/章约 24 万字。
> 主线：寒潮 → 驿站经济 → 北进会垄断 → 5 级兽王 → 契约陷阱 → 高纬门前大会战 → D 突破 → 队内分裂 → 过门。

# 《全民求生：极点》第一卷重排与章纲设计准则

- 版本：v1
- 日期：2026-11-06
- 状态：取代旧版第1—10章章纲与旧第一卷章纲
- 配套文件：`10-章纲体系诊断与改造报告-v1.md`

---

## 0. 这份文件解决什么

旧章纲的问题不是“写得不细”，而是“该锁的没锁”：

- 没有承接状态，AI每章重新开局；
- 没有物品来源，AI默认主角什么都有；
- 没有信息载体，AI用“陌生人私聊”送情报；
- 没有结果与代价，AI写完事件就收；
- 没有禁区，AI自己加频道、加系统、加人物；
- 所有章节同一个尺寸，节奏必然同质化。

这份文件做三件事：

1. 定一套**可执行的章纲/卷纲准则**；
2. 按新准则重写**第1—10章**；
3. 重排**第一卷55章**，并给出试炼线、器物线、关系线、地理线。

## 1. 十二条硬准则

### 准则1：一章一个欲望

本章欲望必须是**具体、可验证、当天能做完或做不完**的事。

- 可以：“在天黑前找到一个能挡雨的落脚点。”
- 不可以：“变强。”“活下去。”“调查这个世界。”

“活下去”是全书目标，不是本章欲望。本章欲望越具体，场景越不会飘。

### 准则2：因果链必须闭合

每章至少跑通一条完整的因果链：

> 因为A，所以他做B；但是C挡住；他选择D；结果E；代价F。

缺任何一环，正文就会用“他觉得/他判断/他决定”来糊弄。

### 准则3：每章写清承接状态

章节工作单第一栏必须写：

- 位置；
- 剩余水/食物；
- 身上伤口；
- 背包里有什么；
- 和谁在一起；
- 已知什么信息；
- 上一章留下了什么麻烦。

**上一章结束时剩多少水，这一章开头就只能有那么多。** 不许“自动补满”。

### 准则4：物品来源三选一

每件物品第一次出现，必须能回答“哪来的”：

| 来源 | 写法要求 | 例子 |
|---|---|---|
| 自己本来就有 | 前文交代，符合身份 | 上班带的背包、美工刀、线手套 |
| 现场拿/抢/买 | 写动作：伸手、塞、掉、丢 | 超市后仓拿水、面包、菜刀、塑料布 |
| 系统给 | 写来源：面板、结算、奖励 | 白门结算的T1便携水囊 |

回答不了来源的物品，一律删掉。军用水壶、伐木柴刀、工兵铲、罗盘，都不许在第一章凭空出现。

### 准则5：信息必须有载体

本书只有五种信息载体：

1. **交易面板**：挂单、成交、成交后私聊；
2. **告示/价目表**：驿站、门前、营地；
3. **人嘴**：活人说的话，有立场、有真假、有代价；
4. **环境**：脚印、尸体、水色、风向、兽径；
5. **系统**：只给结论，不解释，不聊天。

没有“世界频道”“区域频道”“好友0/0”“在线人数”“排行榜”。想知道外面的事，只能靠交易、观察、问人、走路。

### 准则6：每章至少一个专属细节

每章至少有一个**只属于这一章**的东西：

- 一个新物种；
- 一个新地形；
- 一个新器物；
- 一个新规则；
- 一个新谎言；
- 一个新代价。

没有专属细节的章节，就是可替换的章节。可替换的章节，读者会跳。

### 准则7：场景卡只写动作和信息

场景卡不是小说，不写“他感到”“他意识到”“气氛凝重”。

- 可以写：“他用刀背敲了三下泥面，泥面回弹，底下是空的。”
- 不可以写：“他敏锐地察觉到泥下藏着危险。”

**能拍出来的，才写进场景卡。**

### 准则8：章末钩子三选一

每章结尾只能落在三种钩子之一：

1. **危机**：具体的东西正在靠近/正在发生；
2. **信息**：他刚知道一件改变计划的事；
3. **决定**：他刚做一个不能回头的选择。

不写“他知道，真正的考验开始了”“他笑了”“他发誓”。

### 准则9：每章一张禁区清单

禁区要写四类：

- 不能出现的人；
- 不能提前知道的信息；
- 不能出现的词；
- 不能发生的剧情。

**不写禁区，等于默认允许AI自由发挥。**

### 准则10：未来三章只做禁区，不做参考

写第N章时，只告诉模型：

> 第N+1到N+3章会发生什么，所以本章不能碰。

不告诉它“你可以顺着写”。否则第1章就会把第7章的试炼规则讲完。

### 准则11：章型分档，不全3000字

| 章型 | 场景数 | 建议字数 | 任务 |
|---|---:|---:|---|
| 建置章 | 3—4 | 3200—3500 | 新世界、新规则、新目标 |
| 生存章 | 2—3 | 2800—3000 | 一个具体生存问题 |
| 发展章 | 3 | 2800—3000 | 新生态、新工具、新人际 |
| 试炼章 | 3—4 | 3000—3300 | 目标、规则、死亡、结算 |
| 关系章 | 2—3 | 2600—2800 | 两个人怎么从陌生到配合 |
| 高潮章 | 4 | 3300—3600 | 不可逆的选择与代价 |
| 过渡章 | 2 | 2400—2600 | 赶路、恢复、埋钩子 |

### 准则12：每10章一个小爽点，每30章一个卷高潮

- 小爽点：第一次生火、第一口水、第一头猎物、第一次通关、第一次交易赚到；
- 卷高潮：救出女主、第一座纬度门、第一次越档生死战。

爽点不是“打脸”，是**他算得准、忍得住、付得起、走得远**。


### 4.1 场景卡的写法对比

**错误写法：**

> 他意识到这片林子很危险，必须尽快找到水源，否则撑不过今晚。

**正确写法：**

> 他把最后半瓶水倒在瓶盖里，抿了一口，又把瓶盖舔了一遍。然后把空瓶塞回包里，沿着兽径往下走。走了四十步，听见水声。

错误写法在“总结”，正确写法在“动作”。AI会扩写动作，不会扩写总结；总结只会变成空话。

## 5. 新系统规则（卷一使用）

### 5.1 固定面板

落地时自动出现一次，之后只在数值变化时出现。

```
姓名：
阶位：
属性：力 / 敏 / 体 / 心识
装备：主手 / 护具 / 背包
道具卡：
技能：
```

- 没有的栏位写“无”；
- 面板不解释规则，不弹教程；
- 面板不显示好感度、任务列表、地图、排行榜；
- 第一章只出现一次四格面板，约6—8行。

### 5.2 交易面板

- 这是唯一的跨区社交/交易入口；
- 没有世界频道、区域频道、队伍频道、好友列表、在线人数；
- 匿名挂单，系统担保；
- 成交抽成5%；
- 挂单72小时自动下架；
- 每日最多挂5单；
- **成交前不能私聊、不能加好友；成交后才解锁私聊，可自愿加好友；**
- 交易面板初始为空，因为所有人都刚落地，没有东西可卖；
- 信息只能通过交易、告示、人嘴、环境、系统获得。

### 5.3 试炼

- **激活条件**：有临时庇护所、有稳定饮用水、完成首次本土生物猎杀；三条满足后，个人属性面板出现“试炼”页。
- **配额**：每人每月2次，每月1日重置，不累积；进入即消耗，失败/主动退出也消耗。
- **试炼门**：激活后，系统在玩家半径500米内随机生成一座试炼门，位置标在面板上，存在24小时；配额用完不再生成。
- **匹配**：所有试炼星、同色档位、单人池；可能遇到本星没有的种族。
- **颜色**：白 / 黄 / 蓝 / 红 / 紫 / 金 / 黑；颜色越深，对手越强，奖励越高。
- **死亡**：试炼内死亡=真死；失败/退出无奖励，但可带回场内拾取物。
- **时间**：场内4天≈场外1天；单场最长7天。
- **卷一限制**：只开单人试炼；组队试炼从卷二开始。

### 5.4 阶位与属性

沿用旧规则，不改数值：

- 未入流<50 / F50 / E300 / D600 / C1200 / B2400 / A4800 / S10000；
- 只看最高单项，达线即晋阶；
- 1/4铁律：最低项≥floor(最高项÷4)；
- 属性点到账自动灌注，不能存点；
- 非试炼击杀不计属性。

**唯一改动**：删除“落地第7天白门教学关补足F”。第一次白门只给5点，F靠第5—6次试炼达成，不提前。

### 5.5 卷一新增：补阶试炼

- 只在纬度门前开放；
- 申请条件：当前阶位满30天，且最高单项达到下一阶门槛的25%（F冲E即≥75）；
- 形式：连续三场同档试炼，中间不结算，全通才算过关；
- 每人每门一次，失败后30天不能重试；
- 成功结算：按缺口一次性补足到下一阶门槛，不超过门槛；同时执行1/4铁律补足；
- 失败无奖励，不退还配额；
- 这是全卷唯一的“大额补点”，也是卷一结尾从F冲E的主要方式，不允许略写。

### 5.6 物品与器物

- 系统只认系统给的装备/道具卡/技能；
- 现实物品能带进来，也能用，但面板不显示、不享受系统加成；
- T1器物解决一个具体生存痛点，不是万能；
- 每件器物都有重量、消耗、耐久；
- 卷一关键器物链：水囊 → 火种盒 → 帐篷 → 自净水壶 → 工兵铲 → 骨甲/兽筋弓。

## 6. 反模板化规则

### 6.1 套话黑名单

场景卡和正文里禁止出现以下句式：

- “只认看得见的东西”
- “把时间掐在天黑前”
- “数字对上了”
- “他没再犹豫”
- “先算”
- “剩下的路得省着走”
- “伤口还在渗血”
- “背包比昨天轻了一斤”
- “他知道，真正的考验开始了”
- “瞬间”“死死”
- 气味公式：“铁锈味”“臭氧”“臭氧的腥气”“腥气”“焦糊味”“腥臭味”“腐臭味”
- 孤立判断句成段：“脸先着地。”“都能动。”“东西都在。”“他站起来。”“雨还在下。”
- 无意义动作：“拧开闻了闻又拧紧”“擦了两下袋子”“拍了拍身上的土”“深吸一口气”

### 6.2 场景卡不写文学判断

- 不写“他意识到/他判断/他决定/他知道”；
- 不写“气氛/压迫感/危机感”；
- 不写比喻堆砌；
- 只写：谁、在哪、要什么、被什么挡住、做了什么、结果是什么。

### 6.3 每章一个“不能替换”的细节

写完章纲，问一句：

> 如果把这一章换到别的章节，会不会一样成立？

如果会，说明这一章没有专属细节，重写。

### 6.4 情绪曲线按“压—小扬—压—爆”

- 压：缺水/受伤/被跟踪/食物见底；
- 小扬：找到水/生起火/修好工具/完成交易；
- 再压：水被污染/买家压价/异族出现/帐篷破了；
- 爆：第一次猎杀/第一次通关/救出女主/过门。

不要每章都爆。爆多了，读者会疲劳。

### 6.5 开篇三要素与日常配额

每章第一句必须给三样东西：**地名 + 具体地点 + 时间**。

- 可以：“江城市，老城区，好运来生活超市。二十一点四十三分。”
- 不可以：“冷柜又漏水了。”

日常段最多两段，每段只承担一个信息：

1. 第一段：地点、时间、一个具体的小麻烦；
2. 第二段：他对这个麻烦的态度（一句抱怨或一个动作），顺带交代身份。

日常结束，必须直接进异常。超过两段，就是在拖。

### 6.6 每章至少一句“人话”

主角每章至少有一次口语表达，可以是对话、自言自语、心里骂一句。

- 可以：“试炼吗，起码比当个社畜好吧，那就来吧。”
- 可以：“看来是个虚的。”
- 不可以：全章只有动作，没有一句台词。

冷硬不等于哑。人话的作用是让读者确认这是个活人，不是执行剧本的机器。

### 6.7 系统文本用【】包裹

- 系统公告每句独立成段，外层加【】；
- 面板字段整行加【】，字段内用“｜”分隔；
- 正文叙述里提到面板，不加符号；
- 固定面板合计 ≤8 行/章，属性面板全章只出现一次。

### 12.4 关键限制：场景卡只有四样会被渲染

平台的 `toChapterScenes` 只读取：

`title / goal / conflict / turn / props / characters / words / location / bigSceneId / change / envQuota`

以下内容**不会**进入写稿 Prompt：

- 进入状态、退出状态；
- 信息变化；
- 物品动作；
- 本场禁止项；
- 场景的情绪判断。

所以这些内容必须写进 `user_guidance`（最高优先级），或者压缩进 `goal/conflict/turn` 的句子里。**写在 scenes_json 的额外字段里，等于没写。**

### 12.5 user_guidance 的结构

每章 `user_guidance` 按以下顺序写，不要改顺序：

```
【最高优先级：本章工作单】
章型 / 字数 / 时间 / 地点
承接：
本章欲望：
阻力：
关键选择：
结果与代价：
信息释放（读者/男主/女主/对手/禁止提前知道）：
物品账（来源/消耗/获得/丢失）：
伏笔：
章末钩子：
禁区：
连续性：

【场景执行】
场景1｜标题｜约X字
进入状态：……
目标：……
阻力：……
转折：……
退出状态：……
信息变化：……
物品动作：……
环境配额：X句
禁止：……

【写作红线】
1. 不写心里总结，只写动作、对话、面板、环境。
2. 不写“瞬间、死死、仿佛、仿佛看到了希望”等套话。
3. 不提前写下一章的人、地点、规则。
4. 面板只写字段和数值，不写解释。
```

### 12.6 notes 的结构

`notes` 不保证进入写稿 Prompt，只作为人工复核和后续章衔接用。固定三块：

```
【承接】上一章结束时：位置/水/食物/伤口/装备/同行者/已知信息
【物品账】来源/消耗/获得/丢失
【禁区】不能出现的人/信息/词/剧情
```

### 12.7 未来三章注入方式

写第N章时，只注入第N+1到N+3章的“禁区摘要”，不注入完整蓝图：

```
【后续剧情禁区】
第N+1章会发生：……
第N+2章会发生：……
第N+3章会发生：……
因此本章不能出现：上述人物、地点、规则、结果。
```

这样既防止越界，又不会让模型提前消费后面的剧情。

## 14. 一句话总结

旧章纲写的是“他做了什么”，新章纲写的是：

> **他为什么必须做、他有什么选择、他选了什么、付出什么、下一章为什么还得走。**

把这句话锁进每一张工作单，正文的偏移量就会降下来。

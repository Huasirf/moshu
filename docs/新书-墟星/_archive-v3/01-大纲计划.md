# 《全民求生：极点》大纲计划

> 配套设定：[00-世界设定-v3.md](./00-世界设定-v3.md)
> 原则：卷纲只定目标与完成条件，章纲按生存日历推进；目标达成就收卷，不锁死章节数。
> 篇幅：36 个月、四卷 × 9 个月、约 320 章、96 万字。

---

## 一、双主角

### 商临野（男主）

- 21 岁，大三，材料科学与工程；175cm，偏瘦，手上有焊疤。
- 主战斗 + 野外工程：结构视界拆战技、拆装备、拆异族武器、拆遗迹机关、拆地形。
- 性格：先算账再动手，不轻易许诺；答应的事一定做；对敌人冷，对自己人笨拙。
- 前史：19 岁天才（低温焊接合金）→ 20 岁实验室爆燃、被导师推责、成果被顶替、劝退 → 打工一年 → 来墟星前刚被最后一个项目踢出局。
- 动机：不为复仇，不为亲人，只为变强、活下去；把“被人一句话抹掉”的处境甩在身后。

### 苏晚棠（女主）

- 18 岁，160cm；圆脸、马尾，手指关节有旧伤；瘦，但不弱。
- 看着慢半拍，是因为她在听；答“好”之前会先想一遍。
- 被俘七天没哭，记守卫换班、磨绳子、策划过自己逃；不服软，也不硬顶。
- 缺陷：长时间用回声会耳鸣（听觉 -50%，2 小时）、正面战力弱、没学过契约文本。
- 天赋“回声”：静立 10 秒，听见空腔、脚步、心跳、水脉、墙体裂纹；F 100m 至 A 30km。战斗给 0.5–1 秒预警。

### 关系

- 他开路，她听路；他决定方向，她决定什么时候停。
- 他负责打、修、算；她负责听、记、预警。两个人都不依附谁。
- 慢热、一对一、不后宫；靠一次次“把后背交出去”推进。

### 队伍

- 核心两人 + 灰尾（风犬幼崽）+ 轮换异族向导；不固定五人。
- 灰尾：找水、找食、辨兽迹、夜间低吼预警、能背 8kg；不能进试炼。进门前必须安置：默认营地留守、留 7 天口粮；驿站就在旁边时才寄养（1 星币/天）。

## 二、全书主线

### 一句话

从“活过第一个月”，到“走进极点的星门”——中间每一步都要用阶位、星币、器物和人命去换。

### 四层目标

| 层 | 起点 | 终点 |
|---|---|---|
| 生存线 | 赤道雨林，未入流 | 撑过星门 30 天 |
| 成长线 | 男主未入流、女主 F | 男主 C、女主 D |
| 地理线 | 低纬区 | 极区星门 |
| 情感线 | 救回来的人 | 敢把后背交出去、一起进门 |

### 终局问题

墟星是苗圃还是坟场？——它筛的不是最强的人，是**能带着技术和人一起走到门口的人**。

- **有效行军日**：纯步行 20–30km/天是理论值；扣掉每月 4 个试炼日、寒潮/暴雨/磁暴封路、找水绕路、伤病、驿站补给的停留，实际每月有效行军约 18–22 天。36 个月走完 10,000km，靠的就是这个折算。

## 四、每卷目标与完成条件

### 第一卷 一片荒野（1–9 月，低纬区）

**阶段目标**：从落地到第一座纬度门。

- 剧情：落地雨林 → 第一夜 → 降临试炼补 F → 第一次驿站 → 第一次交易 → 北上 → 第 4 月救苏晚棠 → 同行 → 第一座门 → E 突破 → 过门。
- 关系：从“救回来的人”到“敢把后背交出去”；卷末她第一次独自听门。
- 队伍：两人 + 灰尾；中途跟过 1–2 个轮换成员，卷末散。
- 器物：T1 全套（水/食/住/行）；T2 折叠工作台、防兽帐篷、生命探测仪。
- 星币：从 0 到能买得起一张门位情报（约 200）。
- 完成条件：
  - [ ] 男主 E（306），女主 F（约 90）
  - [ ] 救出苏晚棠，同行超过 30 天
  - [ ] 灰尾入队，至少救过一次场
  - [ ] 走完低纬区 1,330km，抵达第一座纬度门
  - [ ] 拿到第一枚**完整低纬印记**（3 枚碎片兑换）
  - [ ] 第一次杀人或第一次放人，留下信用痕迹
  - [ ] 过门，进入中纬区
- 卷末钩子：门在身后关闭；区域频道刷出“中纬区第一场寒潮，还有 40 天”。

### 第二卷 一道门（10–18 月，中纬区）

**阶段目标**：从两个人到一支能谈判、能打仗、能散伙的小队。

- 剧情：中纬第一站 → 驿站物价 → 第一次悬赏 → 寒潮毁营 → 北进会垄断门位与坐标 → 兽王巢 → 交易行假货/契约陷阱 → 高纬门前大会战 → D 突破 → 队内分裂 → 过门。
- 关系：她开始单独去驿站核价、核对契约；他开始把“决定”交给她一次。
- 队伍：两人 + 灰尾 + 2–3 个轮换成员；卷末分裂成 2 vs 2，各走各的。
- 器物：T3 空间箱、凝水徽章升级、兽核炉图纸（做不出来，留到卷三）。
- 完成条件：
  - [ ] 男主 D（606），女主 E（300）
  - [ ] 穿越中纬区 4,000km
  - [ ] 拿到第二枚**完整中纬印记**（3 枚碎片兑换）
  - [ ] 与北进会正面交锋一次，赢或全身而退
  - [ ] 重创/驱走一头 5 级兽王（靠陷阱、地形、队伍），取得兽王皮与碎片
  - [ ] 队伍分裂一次，且没有回头
  - [ ] 过门，进入高纬区
- 卷末钩子：门后第一夜 -25℃；极夜还有 20 天；粮只够 12 天。

### 第三卷 一场极夜（19–27 月，高纬区）

**阶段目标**：在最不适合活的地方，活 9 个月。

- 剧情：极夜来临 → 食物与燃料危机 → 地下遗迹/温泉 → 与异族谈判 → 队友出卖坐标 → 大规模 PVP → 引走/重创 6 级兽王 → 极夜最长夜 → 弃营逃亡 → 找到极地门 → C 突破 → 冲门。
- 关系：她耳鸣加重开始隐瞒；他第一次为她放弃一次试炼；两人第一次真正吵架。
- 队伍：只剩两人 + 灰尾；轮换成员一个背叛、一个死亡。
- 器物：兽核炉 T5（团队级）、恒温仓 T5；空间箱升级。
- 完成条件：
  - [ ] 男主 C（1200），女主 D（600）
  - [ ] 穿越高纬区 3,550km
  - [ ] 拿到第三枚**完整高纬印记**（3 枚碎片兑换；极区门要查验）
  - [ ] 撑过极夜最长夜
  - [ ] 6 级兽王：引走、重创、或联合三支队伍围杀，取得兽核与一枚印记碎片（不写单队正面击杀）
  - [ ] 一次背叛、一次死亡、一次和解
  - [ ] 过门，进入极区
- 卷末钩子：极区磁暴；三座激活塔在三个方向；星门还有 9 个月开启。

### 第四卷 一扇门（28–36 月，极区）

**阶段目标**：把三枚印记插进三座激活塔，撑过星门 30 天。

- 剧情：极区磁暴 → 三座激活塔的三个方向 → 极寒生存 → 心魔/镜像战斗 → 救人还是拿钥匙 → 三塔点亮 → 第 36 月 1 日星门全开 → 万族降临 → 清关点 → 反杀 → 主力降临 → 最后十天 → 走进星门。
- 关系：她做一次最终决定；他把命交给她一次；灰尾差点死。
- 队伍：两人 + 灰尾；临时联合其他幸存者，但不结盟到底。
- 完成条件：
  - [ ] 三枚印记全部到手，并分别插入三座激活塔
  - [ ] 男主 C（1200–1500），女主 D（600–800）
  - [ ] 击杀至少 3 名降临者，夺到星空装备
  - [ ] 撑过星门 30 天，活着
  - [ ] 两人 + 灰尾一起走进星门
- 卷末钩子：门后是星空；本书到此为止。

## 五、章纲生成规则

### 日历驱动

- 每月 1 日、16 日：试炼窗口，各 5 天，每窗最多 2 门。
- 每窗最多 2 门；全书只展开关键场次，其余一句带过。
- 赶路占天数：低纬 20–30km/天，中纬 15–25km/天，高纬 10–20km/天，极区 5–15km/天。
- 每月至少一次补给/交易/驿站；每 3–5 章一次“水/食/火/宿/警戒”的具体细节。
- 黑潮按 2km/天推进；每月在区域频道刷一次“南界后退 XX km”。

### 章纲表列

| 章号 | 日期 | 地点 | 主事件 | 推进目标 | 数值变化 | 钩子层 | 伏笔 |
|---|---|---|---|---|---|---|---|

- 章号可后填；先排事件，再按节奏切章。
- 每章至少一个决策、一个代价；不写“主角轻松获胜”。
- 每 4 章一个小闭环（3:1）；每章结尾留动作或决定。

### 填纲顺序

1. 先列本卷 30–40 个事件（含卷目标、关系节点、威胁节点、器物节点）。
2. 按日历排期，标出试炼窗口、驿站、寒潮/极夜、门节点。
3. 按 3:1 切章，检查数值目标是否够用（属性、星币、器物、粮）。
4. 目标全部达成即收卷，不硬凑章节数。

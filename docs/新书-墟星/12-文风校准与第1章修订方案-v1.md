## 1. 你这次实际改了什么

把反馈拆开，是六件事，不是一件：

| # | 你的意见 | 本质 |
|---|---|---|
| 1 | 日常太多、写得不好 | 开篇信息密度分配错了：日常占了近一半篇幅，挤压了“降临+抢购” |
| 2 | 第一句应先点地点和时间 | 缺“锚点”：读者前三行不知道人在哪、几点 |
| 3 | 系统文本要有符号 | 系统信息和叙述没有视觉分层 |
| 4 | 三分钟里加中等地震 | 抢物资的动机不够硬：倒计时是“被告知”，地震是“被砸到” |
| 5 | “脸先着地。”“都能动。”“东西都在。”不行 | 孤立短句成段，是典型 AI 腔 |
| 6 | 铁锈味、臭氧、腥气禁用；闻水、擦袋子删掉 | 气味公式 + 无意义动作 |
| 7 | 主角要有一句人话：“起码比当个社畜好吧，那就来吧。” | 主角前 3000 字全程哑巴，像执行任务的机器 |

其中第 5 条和第 7 条最要紧。第 5 条是句法病，第 7 条是人味病。

## 2. 现有试产稿的三个病灶

### 2.1 病灶一：日常 1400 字，占了全章 45%

现稿从“冷柜漏水”写到“玻璃门外人开始跑”，一共 1400 余字。里面包括：拖把、报修单、盘点单、关东煮、老太太买盐、中年男人买烟、外卖员、火锅广告屏。

这些细节单看都对，但连起来是“便利店夜班观察日记”，不是“世界崩坏前最后三分钟”。

**读者要看的是：一个普通人正在过普通的一分钟，然后这一分钟被掐断。**

日常只能承担两件事：

1. 让读者知道他在哪、几点、干什么；
2. 让读者看到他是个什么人（会算、话少、不占便宜）。

超过两段，就是在拖。

### 2.2 病灶二：孤立短句成段

现稿有三处：

```
脸先着地。
都能动。
东西都在。
```

这三句的问题不是短，是**没有主语、没有动作对象、没有结果**，靠换行制造“力度”。这是 AI 写打斗和灾难时最典型的偷懒手法：用排版代替内容。

单句成段可以用，但必须满足一条：**这一句里有完整的主谓宾，且结果是新的。**

- 可以：“水在脚边摊开，混着泥和纸屑。”（有对象、有结果）
- 不可以：“东西都在。”（谁的东西？在哪？在意味着什么？）

### 2.3 病灶三：无意义动作与主角失语

- “他把水拧开，闻了闻，没喝，又拧紧。”——动作没有改变任何状态，删。
- “面包的袋子进了泥，他拿袖子擦了两下。”——擦完还是脏的，不改变决策，删。
- 全章主角只说过“别碰”两个字，其余全是动作。冷硬不等于哑。

**冷硬求生文的主角不是不讲话，是讲话不带情绪解释。** 他可以吐槽，可以骂一句，可以说一句自嘲，但不能说“我必须活下去”。

## 3. 新文风八条（写进准则）

### 规则1：第一句锁“地名+地点+时间”

开篇第一句必须是可定位的三要素，不许从天气、声音、动作起手。

- 可以：“江城市，老城区，好运来生活超市。二十一点四十三分。”
- 不可以：“冷柜又漏水了。”

**理由**：读者前三行要建立空间坐标，否则后面所有动作都是悬空的。

### 规则2：日常不超过两段，且必须有一个“抱怨”

- 第一段：地点、时间、一个具体的小麻烦（漏水/挤车/加班）；
- 第二段：他对这个麻烦的态度（一句吐槽或一个动作），顺带交代身份。

日常段结束，必须直接进异常。

- 反例：从冷柜写到关东煮、写到来买盐的老太太、写到买烟的男人、写到外卖员。
- 正例：漏水 → 报修三次没人来 → 第七个月夜班 → 屏幕变蓝。

### 规则3：每章至少一句“人话”

主角每章至少有一次口语表达，可以是对话，可以是自言自语，可以是心里骂一句。

- 可以：“试炼吗，起码比当个社畜好吧，那就来吧。”
- 可以：“这就是试炼世界？没想到是真的。”
- 不可以：“他判断，这里不适合久留。”

人话的作用：让读者确认这是个活人，不是执行剧本的 AI。

### 规则4：禁止孤立判断句成段

单个短句独立成段，必须满足“主谓宾完整 + 结果为新”。

- 禁：“脸先着地。”“都能动。”“东西都在。”“他站起来。”“雨还在下。”
- 改：“商临野脸朝下摔进泥里，却没有痛感传来。”“他动了动手脚，撑起来，没有一处不听使唤。”

### 规则5：动作必须改变状态

一个动作写进正文，至少要改变以下一项：位置、资源、身体、信息、关系。

- 闻水不喝 → 不改变任何一项 → 删；
- 擦袋子上的泥 → 不改变 → 删；
- 把饭盒倒扣接雨 → 改变资源（开始有水）→ 留；
- 拿刀劈面板 → 改变信息（确认面板是虚的）→ 留。

### 规则6：系统文本用【】包裹，叙述不包裹

- 系统公告：每句独立成段，外层加【】；
- 面板字段：整行加【】，字段内用“｜”分隔；
- 正文叙述里提到面板，不加符号。

示范：

```
【全民试炼已降临】
【三分钟后，你们将被传送至极点世界，参与文明试炼】
【活下去，抵达极点】
```

```
【姓名：商临野】
【阶位：未入流】
【属性：力4｜敏4｜体4｜心识17】
【装备：无】
【道具卡：无】
【技能：无】
```

**约束不变**：固定面板合计 ≤8 行/章，属性面板全章只出现一次。

### 规则7：气味只写“来源+浓度”，不写“配方”

- 禁：铁锈味、臭氧的腥气、焦糊味、腥臭味、腐臭味；
- 禁：三种以上气味并列；
- 可：泥的味道、雨的味道、血的味道（单一来源，且必须影响判断，例如“血味会引来东西”）。

用户已明确：**铁锈味、臭氧、腥气，三个词全部进禁用表。**

### 规则8：传送可以“无痛”，但必须留对照

“摔进泥里却没有痛感”是个好细节，但它必须是伏笔，不是随手一笔。

- 第1章：落地无痛感 → 他以为是自己麻木了；
- 第5章：被兽抓伤，痛感正常 → 排除“身体坏了”；
- 第7—8章：试炼里受伤，痛感正常 → 排除“试炼空间屏蔽”；
- 第35章：越档重伤，痛到站不起来 → 确认“无痛感”只在传送瞬间发生。

**回收方式**：传送是“搬运”，不是“伤害”，所以不给痛觉。这条不解释，只让读者自己拼出来。

## 5. 第1章重排：四场景、新字数、新节拍

现稿 3121 字，日常 1400 字。重排后目标 3300—3400 字，日常压到 550—650 字。

| 场景 | 内容 | 现字数 | 新字数 | 变化 |
|---|---|---:|---:|---|
| 1 | 日常 + 屏幕变蓝 + 公告三遍 + 地震起 | 1400 | 650 | 砍掉买盐、买烟、关东煮、外卖员、盘点单细节 |
| 2 | 地震中抢物资 + 出发 | 700 | 1150 | 地震成为主动力；抢购动作加密 |
| 3 | 落地 + 清点 + 面板 + 试探 | 800 | 900 | 改成连续段落，删孤立句与无意义动作 |
| 4 | 环境 + 三趾印 + 交易面板 + 钩子 | 700 | 750 | 保留，收紧 |

### 5.1 场景1新节拍（650字）

1. 地点+时间（1 句）；
2. 漏水 + 报修三次没人来（2 段）；
3. 第七个月夜班 + 退货单（1 段，交代身份）；
4. 屏幕变蓝（1 段）；
5. 面板出现（1 段）；
6. 公告三遍（三句独立）；
7. 地震开始（2 段）。

**删除**：老太太买盐、中年男人买烟、关东煮、盘点单数字、冷柜门吸不住、外卖员。
**保留**：漏水、报修单、第七个月、退货单、小周（只留一句）。

### 5.2 地震设计（场景1末尾—场景2全程）

**震级定位**：中等。站不稳、货架倒、灯管爆、天花板落灰、玻璃裂，但不塌楼。

**震感分三层写**：

| 层 | 写法 | 作用 |
|---|---|---|
| 第一下 | 货架上的瓶子成排往下掉，冷柜横着滑出去半米 | 让读者知道“这不是幻觉” |
| 第二下 | 灯管炸了两根，天花板落灰，玻璃门裂了一道 | 让空间变危险，逼人做选择 |
| 余震 | 每十几秒晃一下，人站不住 | 给抢购加时限 |

**地震给剧情的三个好处**：

1. **动机硬**：不用理解试炼，也知道必须现在就动；
2. **秩序崩**：收银台没人管、后仓门被震开、玻璃门卡死，全部合理化；
3. **淘汰弱者**：有人蹲下抱头，有人往外跑，有人开始抢——三类反应，不用写“人群混乱”这种总括。

**地震与公告的顺序**：

```
公告第一遍 → 屏幕蓝、面板出现
公告第二遍 → 第一下震动
公告第三遍 → 第二下加重，光柱落下
政府播报 → 播到一半，余震，断
```

## 6. 开篇地点：两套方案，需要你拍板

你给的示例是“大肥鱼饭店后厨”，但同一段里又出现“饮料区补水饮料”“写退货单”——这是超市语言。两者混在一起，物品账会崩。

### 方案A（推荐）：超市夜班，招牌具体化

```
江城市，老城区，好运来生活超市。二十一点四十三分。
```

- 优点：水、面包、香肠、饼干、菜刀、水果刀、打火机、塑料布、绳、饭盒、手电、电池、胶带、雨披，全部能在后仓和货架拿到，来源链闭合；
- 优点：夜班理货身份成立，退货单、盘点、后仓都合理；
- 改动：只改开头句和日常长度，物品账不动，第2—10章不受影响。

### 方案B：大肥鱼饭店后厨

```
江城市，大肥鱼饭店后厨。二十一点四十三分。
```

- 优点：场景更有辨识度，“后厨”比“超市”更有画面；
- 代价：饭店后厨只能拿到米、面、油、瓶装水、菜刀、点火器；拿不到绳、手电、电池、胶带、雨披、塑料布；
- 连带改动：要么把饭店写成“前店后仓、隔壁是便利店”，要么重写第2—4章的工具链（庇护所、取水、套索全部要换材料）。

**我的判断**：方案A。你要的“具体地名+招牌+时间”的质感，用“好运来生活超市”一样能给，不必牺牲物品来源。

### 如果坚持要“挤公交”开场

那第一章结构要变成：

```
公交站（等车、烦躁、车来）→ 系统降临 → 地震 → 他看见街角超市 → 冲进去抢 → 投放
```

代价：多一个“从车站到超市”的过场，三分钟内跑不完，逻辑上要放宽到“五分钟”或让超市就在站牌后面。**不建议**，会稀释三分钟的紧迫感。

## 0. 一句话文风

**冷硬、具体、有代价的求生文：先给可验证的物理事实，再给判断；不抒情，不解释系统，不让角色白赢。**

## 1. 文风总纲

| 维度 | 要求 | 反面 |
|---|---|---|
| 基调 | 冷峻、克制、工业写实、绝境求生 | 热血喊口号、轻松诙谐、抒情散文 |
| 视角 | 第三人称限知，男主主视角 | 上帝视角解释系统、配角随意开视角 |
| 节奏 | 短句、短段、动作推进；3:1 推进与回收 | 大段心理独白、连续环境铺陈 |
| 情绪 | 不外露；用判断、决定、身体代价表达 | "他很难过""心中五味杂陈" |
| 信息 | 先让读者看见，再解释；系统只给结论 | 系统教程、规则科普、面板堆砌 |
| 爽点 | 靠"算得准、准备足、代价付得起" | 越阶秒杀、无伤通关、天降外挂 |
| 幽默 | 极少；只允许角色自嘲式冷幽默 | 网络梗、插科打诨、吐槽系统 |

**四条铁律**

1. 每章必须有明确状态变化：地点、资源、关系、信息、能力、危险，至少变一项。
2. 每次胜利都要掉东西：血、装备、时间、信用、队友，至少一项。
3. 系统不解释一切：面板只给结论，规则靠人物试错和别人的话露出来。
4. 章末只留动作、决定或危机，不留总结与升华。

## 2. 文风指纹（可量化指标）

> 口径说明：本节的零容忍项、配额与词表以 `设定/06-AI味与模板化描写限制清单.md` 为唯一标准；两处若有出入，以 06 为准，本节保留本书专属示例与量化值。

### 2.1 硬指标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 平均句长 | 12–18 字 | 超过 40 字的句子必须拆 |
| 段落长度 | 1–5 行 | 动作段允许单句成段 |
| 对话占比 | 15%–30% | 荒野章可低于 10%，交易站/谈判章 30%–40% |
| 比喻密度 | ≤2 处/千字 | 比喻必须取自本书物件：兽筋、合金、门框、冻土、兽核 |
| 感官配额 | 每场 1 种主感官 | 气味全章 ≤1 处，且必须写出来源 |
| 系统面板 | 固定面板合计 ≤8 行/章；属性 ≤2 次/章，装备/道具/技能各 ≤1 次/章 | 独立成段，以【】开头，只给结论 |
| 破折号 | ≤2 处/千字 | 只用于打断或补充信息，不用于抒情 |
| 感叹号 | ≤3 个/章 | 不靠标点制造情绪 |
| 省略号 | ≤2 处/章 | 不靠省略号装余味 |
| 重复动作词 | 同一词 ≤1 次/章 | 摩挲、攥紧、深吸一口气、喉结滚动 |
| 信息增量 | ≥1 个新事实/章 | 新地点、新规则、新人物、新资源、新威胁 |
| 章末 | 动作或决定 | 禁止"这一切才刚开始""命运的齿轮" |

### 2.2 语言质感

- **动词优先**：主语＋动词＋对象＋结果。少用"感到、似乎、仿佛"。
- **因果可见**：不写"因为害怕所以后退"，写"他后退半步，脚跟撞上碎石"。
- **数字可算**：只写能用于决策的数——距离、天数、星币、属性、负重、温度、口粮。
- **名词具体**：写"镀锌铁皮"不写"金属材料"；写"三指宽的冻裂"不写"伤口很深"。
- **不解释名词**：新器物第一次出现，用动作带出用途，不写说明书。

### 2.3 正例 / 反例

| 场景 | 反例（AI 腔） | 正例（本书口径） |
|---|---|---|
| 紧张 | 他的心跳如擂鼓，空气中弥漫着令人窒息的气息。 | 倒计时跳到 00:03:12。他把铜芯抵在端子口，手腕一沉。 |
| 受伤 | 剧烈的疼痛让他几乎无法呼吸，冷汗浸透了后背。 | 左肋第三根肋骨那儿一喘就扎，他把腰带又勒紧一格。 |
| 发现危险 | 一股强烈的危机感涌上心头。 | 灰尾的尾巴先夹了下去，喉咙里滚出一声低吼。 |
| 系统信息 | 系统告诉他，通过试炼可以获得属性点。 | 系统只留一句：一级试炼门·生存，限时三天。 |
| 章末 | 他知道，真正的考验才刚刚开始。 | 他把最后半壶水塞进背包，转身往北。 |

## 3. 禁用词与禁用句式

> 口径说明：A/B/C 三组词句与替换建议以 `设定/06-AI味与模板化描写限制清单.md` 为准；本节只补本书专属的慎用词与替换库。

### 3.1 AI 腔九类（全篇禁用）

| # | 模式 | 禁用示例 | 改写方向 |
|---|---|---|---|
| 1 | 哲理对举 | 他不是愤怒，而是对命运感到无力。 | 拆成两个具体动作或后果 |
| 2 | 破折号插入 | 他抬眼——眼底翻涌着情绪——那是难过。 | 直接写动作或一句判断 |
| 3 | 生理反应替代情绪 | 指尖收紧、喉结滚动、胸口发闷。 | 一段最多 2 处生理；第 3 处换动作/对白/决定 |
| 4 | 高频小动作词 | 摩挲、微不可察、不易察觉 | 全章各 ≤1 次，优先写具体动作 |
| 5 | 空洞收尾 | 这就够了。／仅此而已。／如此而已。 | 删；章末只留钩子 |
| 6 | 形容词三连 | 遥远、朦胧、刻骨铭心的回忆 | 一个形容词＋一个可验证细节 |
| 7 | 无意义精确数字 | 沉默三秒、睫毛颤动七下、第三颗纽扣 | 只保留可用于决策的数 |
| 8 | 公文腔过渡词 | 事实上、本质上、毋庸置疑、客观上 | 删，直接写转折后的事实 |
| 9 | 跨体系意象 | 熵与序碰撞、维度折叠、拓扑网络 | 只用本书设定词：结构、承力、裂纹、兽核 |

### 3.2 环境感官套话（全篇禁用）

**气味公式**：`空气/鼻腔 + 弥漫/混杂/交织 + 2–3 个固定气味名词 + 浓烈/刺鼻/令人作呕 + 生理后果`

禁用名词：焦糊味、铁锈味、铁锈腥甜、腥臭味、土腥味、霉味、腐臭味、臭氧味、化工试剂味、血腥味。

禁用搭配：空气中弥漫着、混杂着、交织着、夹杂着、钻进鼻腔、令人作呕、沉甸甸压在胸口、仿佛能拧出水。

**改写原则**：气味必须写出来源物件与位置。

| 反例 | 正例 |
|---|---|
| 空气中弥漫着焦糊味和铁锈味。 | 烧焦的胶皮贴在墙根，铁皮桶里积着锈水。 |
| 一股腥臭味钻进鼻腔，令人作呕。 | 前面横着一具胀开的兽尸，苍蝇贴地飞。 |
| 潮湿的霉味顺着地面往上返。 | 墙角纸箱长了霉斑，地面返潮。 |

**废土滤镜词限额**：阴冷、潮湿、斑驳、腐朽、破败、荒凉、死寂、灰败、狰狞、黏腻——全章合计 ≤2 次，且必须落在具体物件上。

**禁止环境映射情绪**：不写"灯光变暗＝他害怕""空气凝固＝震惊"。

### 3.3 本书专属禁用

| 类别 | 禁止 | 原因 |
|---|---|---|
| 系统 | 系统解释一切、面板教程、属性说明书 | 破坏"只给结论"的规则感 |
| 战斗 | 无代价胜利、轻松获胜、越阶秒杀、无伤通关 | 违反"等级是硬门槛" |
| 结构 | 大段排比、空泛感叹、章末升华 | AI 腔与水文 |
| 题材 | 基地建设、种田、招流民、城市建设、区块 | 本书是行军求生，不是经营 |
| 关系 | 后宫、甜言蜜语、无脑打脸 | 感情线慢热、一对一 |
| 用词 | 试炼卡、卡源、颜色装备、返黄卡、白装 | 本书用"一级/二级试炼门"和"阶"，不用卡 |
| 用词 | "准入"写成报名、审批、名单、配额 | 本书只认等级；可写"准入阶"，但只是门的等级门槛 |
| 叙事 | 上帝视角讲设定、角色替作者科普 | 信息必须从人物处境里长出来 |
| 反应 | "全场震惊""所有人都没想到" | 不写群体反应堆 |

### 3.4 词表（写作时直接替换）

| 禁用/慎用 | 替换 |
|---|---|
| 眸子、瞳孔、眼底 | 眼睛、视线、目光 |
| 嘴角勾起、邪魅一笑 | 笑了一下、嘴角动了动 |
| 心中一凛、心头一沉 | 手停住、呼吸慢了一拍 |
| 深吸一口气 | 把气憋住、胸口鼓了一下 |
| 不容置疑、毋庸置疑 | 直接写结论 |
| 仿佛、宛如、犹如 | 删；或写具体相似点 |
| 氤氲、斑驳、旖旎 | 写具体物件与变化 |
| 命运的齿轮、这一切才刚开始 | 写下一步动作 |
| 五味杂陈、百感交集 | 写他选了哪一个 |
| 与此同时、值得一提的是、综上 | 删 |
| 令人作呕、刺鼻、浓烈 | 写来源与后果 |
| 深不可测、恐怖如斯 | 写等级、距离、伤口、消耗 |
| 瞬间、顿时、猛地（高频） | 每章各 ≤3 次 |

## 4. 句式、段落与格式

### 4.1 段落

- 一段只做一件事：一个动作、一个判断、一条信息。
- 连续动作可合成一段，但不超过 4 句。
- 场景切换用空行，不写"与此同时"。
- 同一场景不重复写环境；第二次进入只写变化。

### 4.2 对话

- 对话不超过 3 轮必须插动作或环境变化。
- 说话人用动作标识，少用"他说道""她问道"。
- 谈判、交易、契约场景允许长对话，但每轮必须推进条件。
- 异族说话短、直、带利益条件；不写文绉绉的异族诗人。

### 4.3 系统信息与面板分层

> 口径源：[06-AI味与模板化描写限制清单.md](file:///F:/MSnovel/全民区块求生/设定/06-AI味与模板化描写限制清单.md) 第 1.7 节 H 组。两处不一致时以 06 为准。

**固定面板只有四类**：属性、装备、道具信息、技能。四类都用 `【】` 字段行，但只在各自该出现的时候出现。

| 类型 | 规格 | 频率 | 触发 |
|---|---|---|---|
| 属性 | 两行：姓名/等阶、四维 | ≤2 次/章 | 落地激活、结算、数值变化、主动确认 |
| 装备 | ≤4 行：主手/护具/背包 | ≤1 次/章 | 清点、换装、耐久变化、丢装备 |
| 道具信息 | ≤3 行，一次一件 | ≤1 次/章 | 首次拿到、首次使用、数量变化 |
| 技能 | ≤3 行，一次一个 | ≤1 次/章 | 首次觉醒、首次使用、状态变化 |

```text
【商临野｜未入流】
【力 4｜敏 4｜体 4｜心识 17】
```

```text
【装备】
【主手 美工刀 T1｜耐久 7/10】
【护具 湿外套｜0 防】
【背包 帆布包｜12/15kg】
```

硬规则：

- 固定面板合计 ≤8 行/章。
- 两处固定面板之间至少隔一个动作或一句对白，不能连着摆。
- 面板只给结论，不解释字段，不写教程，不写"为什么"。
- 同一信息不重复显示；不显示敌人属性、掉落概率、隐藏规则、他人面板。
- 结算不另开 `【结算】` 卡：只更新属性面板两行，再加两句实物结果（环数、器物、耐久、碎片放叙述里）。

**白名单字段**

- 属性：姓名、等阶、力、敏、体、心识。
- 装备：主手、护具、背包、耐久、防御、已用/上限。
- 道具：名称、等阶、效果、剩余、耐久、限制。
- 技能：名称、消耗、范围、状态、冷却。

**禁止进任何固定面板**：第 N 天、试炼日历、门等级表、区域等级表、好友数、门坐标、交易站距离、商城价格、本星人口、边界线速度、伤势、负重、击杀数、材料总表、星币总表。

**聊天已取消；交易面板只写主观操作**

- 本书没有好友、区域、世界、队伍频道。任何 `【好友频道】【区域频道】【世界频道】` 字段卡都是错误。
- 交易面板第一次打开只写：他点开、看见两个页签、系统说一句、他决定问谁。不排 `【商城 未接入】` 这类字段卡。
- 商家私聊只写具体的人：老钱、周姐、赵铁。一次最多三条消息，只留会改变决定的（库存、价格、预留、方向）。
- 交易站不是系统建筑。位置靠烟、路牌、旧地图、他人口中的方向；系统不给坐标。
- 商城/交易站价格只在需要决策时出现，同章最多一次；不写税率、信用分、拍卖倒计时。

**系统单句**

- 独立成段，以【系统】开头；一次一句，一章 ≤2 次。
- 只给规则结论、门信息、区域警告、结算、公告；不写"恭喜""欢迎"，不扩展成多行字段卡，不写进人物对白，不加引号。
- 前三个月不发任务、不给目标、不给门坐标、不给交易站位置。

**世界态势信息**

试炼门位置、区域等级、本星人口、边界线速度、交易站位置，一律不进固定面板。只走环境载体：告示、路牌、旧地图、旧单据、尸体、兽群异常、商人的嘴。每章最多新增 1 条，不 recap、不倒豆子。

### 4.4 章末

三种合法钩子：

1. **危机钩**：门在身后关闭，里面的东西开始动。
2. **信息钩**：旧地图角落写着“第 90 天”，他不知道什么意思。
3. **决定钩**：他把最后半壶水塞进包，转身往北。

禁止：总结本章、预告下一章、抒情升华。

## 5. 章纲设计要求

### 5.1 每章必填字段

| 字段 | 要求 |
|---|---|
| 章号 / 日期 | 日期必须落在生存日历上 |
| 地点 | 具体到纬度区、地貌、距离下一站 |
| 主事件 | 一句话，动词开头 |
| 推进目标 | 本章改变了什么（地点/资源/关系/信息/能力/危险） |
| 数值变化 | 属性、星币、口粮、水、器物耐久，至少一项 |
| 钩子层 | 危机/信息/关系/目标，至少两层 |
| 伏笔 | 埋什么、何时回收 |
| 场景锁 | 地点、时间、在场人、可携带物、环境配额、禁止事项 |
| 代价 | 本章付出了什么 |

### 5.2 章纲五条硬规则

1. **一章一个决策、一个代价**：没有代价的章节不许立项。
2. **3:1 节奏**：三章推进，一章回收；回收章也要有钩子。
3. **不写教学关**：除第 4–5 章降临试炼，任何试炼不得写成说明书。
4. **不重复钩子**：上一章用过"兽群逼近"，本章换危机类型。
5. **数值可核**：章纲里的属性、星币、粮水必须能和卷账对上。

### 5.3 日历与距离

- 试炼门随机刷新，存在 3–7 天；不设每月固定窗口，不设门坐标。
- 赶路：低纬 20–30km/天，中纬 15–25km/天，高纬 10–20km/天，极区 5–15km/天。
- 第一卷前 30 天不写交易站；第 31 天后每 10–15 章可去一次交易站。
- 每 3–5 章写一次水/食/火/宿/警戒的具体细节。
- 第 90 天前不写边界线；第 90 天系统公告后，边界线每月北移约 60km，只用死林、咸水、北逃兽群表现，不写速度表。

### 5.4 场景锁写法

每场开头先锁六项，生成时不得越界：

```text
场景锁
- 地点：低纬雨林，距投放点 18km，溪谷北岸
- 时间：第 3 天，傍晚，雨后
- 在场：商临野、灰尾；远处 1 级兽群
- 携带：1.5L 矿泉水（满）、打火机（受潮）、菜刀、塑料布、12kg 背包
- 环境配额：1 句（只写水位与泥）
- 禁止：不写系统解释、不写第二处气味、不写回忆
```

### 5.5 章纲反例

| 反例 | 问题 |
|---|---|
| 主角轻松通过试炼，获得大量属性 | 无代价、数值跳变 |
| 系统详细讲解试炼规则 | 教程化，破坏规则感 |
| 他想起童年，心中五味杂陈 | 无功能回忆，AI 腔 |
| 与此同时，北进会也在行动 | 上帝视角，场景硬切 |

## 6. 大纲设计要求

### 6.1 四层目标

| 层 | 起点 | 终点 |
|---|---|---|
| 生存线 | 赤道雨林，未入流 | 撑过星门 30 天 |
| 成长线 | 男主未入流、女主 F | 男主 C、女主 D |
| 地理线 | 低纬区 | 极区星门 |
| 情感线 | 救回来的人 | 敢把后背交出去、一起进门 |

### 6.2 卷纲规则

- 卷纲只定目标与完成条件，不锁死章节数；目标达成就收卷。
- 四卷共 380 章、约 95 万字；卷一只写第 1–3 月 90 章，不跨到中纬。
- 每卷必须写清：阶段目标、剧情节点、关系变化、队伍变化、器物变化、完成条件、卷末钩子。
- 完成条件用可勾选清单，不用形容词。

### 6.3 属性账校验

- 属性点只从试炼结算来；灵植、器物、装备不直接加属性。
- 只看最高单项，达线即晋阶，不设半步阶。
- 每跨一大阶，四维 +20%，只用于战斗，不计入下一阶门槛。
- 卷末必须达线：卷一 E306、卷二 D606、卷三 C1200、卷四 C1200–1500。
- 章纲中的试炼场为累计场次，只展开关键场，其余一句带过。

### 6.4 伏笔三层

| 层 | 数量 | 示例 |
|---|---|---|
| 卷内 | 3 埋 2 收 | 灰尾怕被丢下 → 卷三弃营时它没跑 |
| 跨卷 | 每卷 1–2 条 | 北进会门位账本 → 卷二引爆 |
| 终局 | 1 条主线 | 墟星是苗圃还是坟场 |

- 伏笔必须有载体：物件、伤口、一句话、一个坐标。
- 不允许"后期再说"式空埋；埋下时就要想好回收章。

### 6.5 大纲禁忌

- 不引入无法回收的势力和人物。
- 不让数值跳变（如一章从 F 到 D）。
- 不写"主角不知道自己已经被人盯上"这种靠旁白造悬念。
- 不用"神秘老人""黑衣人"当工具人。
- 不把四区写成四个独立副本；每区必须承接上一区的资源与关系。

## 7. 资产生成要求

### 7.1 人物卡

必填：姓名、年龄、身高、身份、前史、动机、性格三条、能力、缺陷、代价、关系、人物弧、死亡条件。

- 命名：中文 2–3 字，不用生僻字；异族用"族名＋职位"（骨鞅、契无咎）。
- 每人必须有缺陷和代价；不允许全能型。
- 配角的动机靠利益和信息差，不靠"他就是坏"。
- 主角能力必须有硬限制：结构视界九条限制不得删改。

### 7.2 地点 / 地图节点

必填：名称、区域等级、距上一节点距离、气候、资源、威胁、是否有交易站/试炼门痕迹。

- 每个地点至少 1 个可操作资源＋1 个致命威胁。
- 地名用功能名或地貌名：断水哨站、锈犬巢穴、第三信标；不用"幽冥谷""死亡深渊"式空词。

### 7.3 器物

必填：名称、等级 T1–T7、重量、能源、耐久、效果、代价、获取途径。

- 不写无限容量、无代价、永久免伤。
- T5 以上是团队级可展开器物，是"能带走的营地"，不是基地。
- 每件器物至少用三次；只用一次的道具不进资产库。

### 7.4 兽 / 异族

必填：等级 1–7、习性、攻击方式、弱点、掉落、兽核、活动范围。

- 不写"实力深不可测""气息恐怖"；写等级、距离、伤口、消耗。
- 兽王必须有击杀条件：陷阱、地形、队伍、代价。

### 7.5 组织

必填：目标、铁律 3 条、资产、死穴、关系网、代表角色。

- 组织的强大用资产和规则表现，不用"势力庞大"。

### 7.6 伏笔

必填：埋设章、回收章、载体、提醒句、不可提前解释。

### 7.7 时间线与数值表

- 每月记录：边界线北移 km、男主/女主属性、星币、口粮、水、关键器物耐久。
- 章纲与正文数值不一致时，以时间线表为准，回改正文。

### 7.8 资产生成禁忌

- 不与四区、阶位、试炼门等级冲突。
- 不生成无法用三次以上的道具。
- 不生成"神秘老人"式工具人。
- 不给配角开上帝视角。
- 同一卷不出现两个功能完全相同的势力。

## 8. 生成与审稿流程

### 8.1 生成前

1. 读本章场景锁、人物状态、上一章钩子。
2. 读禁用词表与文风指纹。
3. 确认本章的决策、代价、状态变化。

### 8.2 生成中五查

- 视角有没有越界？
- 数值和章纲对不对？
- 携带物有没有凭空出现？
- 环境配额有没有超？
- 系统信息格式对不对？

### 8.3 生成后自检十条

- [ ] 平均句长 ≤18 字，没有 40 字以上长句
- [ ] 没有"不是…而是…"、破折号插入、形容词三连
- [ ] 没有固定气味名词堆叠、废土滤镜词 ≤2
- [ ] 生理描写一段 ≤2 处
- [ ] 没有无意义精确数字
- [ ] 没有"事实上/本质上/毋庸置疑"
- [ ] 固定面板只有属性/装备/道具/技能四类，合计 ≤8 行；无聊天/频道/交易面板/区域等级/边界线状态卡
- [ ] 系统没有发任务、给门坐标、给交易站位置；交易面板与商家私聊写成主观操作
- [ ] 本章有一个决策、一个代价、一个状态变化
- [ ] 章末是动作/信息/决定，不是总结
- [ ] 与上一章没有重复钩子

### 8.4 审稿维度

在通用审稿之外，本书追加：

1. AI 腔共现：八类模式命中 ≥3 类记 warning，≥5 类记 error。
2. 环境感官套话：固定气味词、气味公式、生理后果尾巴。
3. 设定口径：试炼门等级/阶位/器物等级是否混用。
4. 代价检查：本章胜利是否掉了东西。
5. 视角检查：是否出现上帝视角或配角视角。

## 10. 一页速查卡

```text
写每一章之前：
1. 这场在哪？距上一站多远？
2. 他带了什么？还剩多少水、粮、耐久？
3. 本章的决策是什么？代价是什么？
4. 章末钩子是危机、信息，还是决定？

写每一段之前：
1. 这段在推进动作、给危险信息，还是在做判断？
2. 三者都不是——删。
3. 有没有"不是…而是…"、破折号、三连形容词、气味公式？
4. 有没有不能用来做决策的数字？

写完之后：
1. 遮住名字，还能认出是这本书吗？
2. 删掉所有形容词，事实还成立吗？
3. 主角赢了，掉了什么？
```

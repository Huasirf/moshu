# 《全民求生：极点》章纲体系诊断与改造报告

- 版本：v1
- 日期：2026-11-06
- 范围：章纲格式、剧情结构、开篇序列、信息系统、试炼节奏
- 结论：旧纲除“救女主”原型外，建议整体回炉；先用新模板重写第一卷前10章，验收通过后再批量扩展。

## 0. 一页结论

| 问题 | 判断 |
|---|---|
| 章纲是不是“不够细”？ | 不是细不细的问题，是“锁没锁住”的问题。因果、信息、物品来源、禁区都没有锁，AI只能靠套路补空。 |
| 现在的4场景×3000字模板 | 把建置章、生存章、试炼章、高潮章压成同一个尺寸，节奏必然同质化。 |
| 全球/区域聊天 | 建议删除。只保留交易面板；交易成交后才能私聊、加好友。 |
| 老K | 前期不出现。刚落地时所有人既没资源也没信息，信息中间人没有交易基础。等黑潮出现、有人开始被南边赶着走，他才作为“黑潮情报交易者”登场。 |
| 试炼 | 生存适应后激活；每月2次单人试炼；卷一不做团队场。 |
| 开篇 | 按“最后三分钟”重写：现实日常→系统公告→光柱→政府播报→混乱→抢购→投放→四格面板→交易面板→主线目标。 |
| 旧155章 | 除救女主原型、双主角能力、基础世界规则外，全部作废；先重写前10章验证模板，再重建第一卷。 |

一句话：**当前章纲写的是“发生了什么”，正文需要的是“为什么发生、他怎么选、付出什么、下一章为什么必须继续”。**

## 1. 现状诊断

### 1.1 当前章纲的实际结构

平台当前蓝图共155章，第一卷81章。结构统计如下：

| 项目 | 数据 |
|---|---|
| 总章数 | 155章 |
| 每章目标字数 | 全部3000字 |
| 场景数量 | 114章4场景，41章5场景 |
| 单场平均字数 | 703.5字 |
| 章型分布 | 建置6、铺垫23、发展35、转折30、冲突28、高潮23、收尾10 |
| 场景字段 | goal、conflict、turn、props、characters、words、location、change、envQuota |

这组数据说明两个问题：

1. **所有章节被压成同一尺寸。** 建置章、生存章、试炼章、卷末高潮章，全部3000字、4到5场、每场700字左右。读者感受不到“这一章是过渡，下一章是高潮”。
2. **场景卡只有“目标/冲突/转折”三件套。** 它更像“事件提示”，不是“可执行的工作单”。AI拿到这三行，只能自己补人物状态、物品来源、信息真假、场景进出状态，补着补着就补成了套路。

### 1.2 八个结构性缺陷

#### 缺陷一：事件表代替因果链

当前蓝图的关键事件是压缩的事件列表，例如第1章只写了一句话：

> 现实最后三分钟，全城公告倒计时；光柱升起，他带着背包、柴刀、水壶落地。

这句话里有“发生了什么”，但没有回答：

- 背包、柴刀、水壶是哪来的？
- 他为什么会在那个位置？
- 最后三分钟他做了什么选择？
- 他放弃了什么？
- 落地时他的状态是什么？

正文只能凭空解释“这些东西没一样是系统给的”，读者却看不到“获得”的动作。**物品没有来源，人物就没有选择；人物没有选择，开篇就没有戏。**

#### 缺陷二：场景卡缺少“进入状态”和“退出状态”

当前场景卡没有写：

- 上一场结束时，他在哪、还剩多少水、伤在哪、背包里有什么、知道什么。
- 这一场结束时，他的位置、资源、关系、信息、能力哪一项变了。

结果就是：AI每一场都重新开局。上一场刚喝完水，下一场又“嗓子干得冒烟”；上一场刚处理完伤口，下一场又“伤口还在渗血”；上一场背包已经轻了，下一场又“背包比昨天轻了一斤”。**不是AI不会写连续，是章纲没有给它连续的状态。**

#### 缺陷三：物品与资源没有来源

当前第1章的“柴刀、水壶”，第1章正文里的“军靴、短刀、罗盘、铁皮水壶、工兵铲、营养膏、火柴”，都属于“默认拥有”。读者会立刻产生疑问：

- 一个普通打工人，为什么随身带短刀、罗盘、工兵铲？
- 军用水壶是哪来的？
- 他凭什么在落地前就准备好这些？

正确的做法只有三种来源：

1. **自己本来就有**：必须在前文交代，且符合人物身份。
2. **现场抢/买的**：必须写“伸手、拿、塞、掉、丢”的动作。
3. **系统/试炼给的**：必须写“面板/结算/奖励”的来源。

**每件物品第一次出现，必须能回答“哪来的”。** 回答不了，就删掉。

#### 缺陷四：信息差与信息载体缺失

第2章老K在区域频道发水源坐标，男主点开老K，好友栏从0/0变成1/1，然后照着走。第3章老K又私聊“驿站收兽筋，十二星币一根”。

这里面缺了四个关键问题：

- 老K为什么知道水源？
- 他为什么免费告诉男主？
- 男主凭什么信？
- 信息是真的还是假的？

没有交易、没有验证、没有代价，老K就成了免费NPC。**信息不是背景音，信息是商品，是筹码，是陷阱。** 谁说的、为什么说、说了之后谁得利，必须写清楚。

#### 缺陷五：禁区缺失

当前章纲没有“本章不能出现什么”。于是第1章正文出现了：

- 世界频道、区域频道、交易行、试炼日历、人口、黑潮；
- 好友0/0；
- “死死”“瞬间”等禁用词；
- 大段面板解释。

这些都不在章纲里，但AI会自己加。**不写禁区，等于默认允许AI自由发挥。**

#### 缺陷六：节奏同质化

155章全部3000字，114章4场景。每章都是“目标—冲突—转折—结果”的同一套节拍。结果：

- 过渡章和高潮章一样长；
- 生存章和试炼章一样重；
- 每章都在赶路、找水、生火、交易、受伤，读者很快疲劳；
- 真正的高潮（第一次试炼、救女主、第一座门）没有足够的篇幅和场景密度。

#### 缺陷七：套话污染

对661个场景卡的goal/conflict/turn做统计，以下句子高频重复：

| 套话 | 出现次数 |
|---|---:|
| 只认看得见的东西 | 49 |
| 把时间掐在天黑前 | 50 |
| 数字对上了 | 29 |
| 他没再犹豫 | 32 |
| 先算 | 46 |

这些句子本身不算错，但当它们反复出现在不同章节的场景卡里，AI就会把它们直接扩写进正文，形成：

- 每章都有“他没再犹豫”；
- 每章都有人“只认看得见的东西”；
- 每章男主都在“先算”；
- 每章都在“把时间掐在天黑前”。

这不是文笔问题，是**章纲层面的模板污染**。章纲先套路，正文必然套路。

#### 缺陷八：未来蓝图注入导致越界

写稿阶段会注入后3章的关键事件。模型看到后面的剧情，就容易提前消费：

- 第1章就把试炼规则讲完；
- 第2章就把交易关系建立完；
- 第3章就把后面的冲突预演完。

**未来蓝图应该作为“禁区清单”，不是“写作参考”。** 告诉模型“后面会发生什么，所以这一章不能碰”，而不是“后面会发生什么，你可以顺着写”。

### 1.3 具体章节复盘

#### 第1章《最后三分钟》

- 蓝图只有一段话，没有场景级因果。
- 正文从雨林落地开始，没有现实三分钟、没有系统公告、没有政府播报、没有抢购。
- 系统面板一次性塞入世界频道、区域频道、交易行、试炼日历、人口、黑潮。
- 物品凭空出现，正文用一段解释“这些东西没一样是系统给的”。
- 出现“死死”“瞬间”等禁用词。

**问题不在文笔，在章纲：它没有锁开局顺序、没有锁物品来源、没有锁面板字段、没有锁禁区。**

#### 第2章《溪边的火》

- 老K在区域频道发水源坐标；
- 男主加好友，好友0/0→1/1；
- 老K私聊“北坡夜雾不能走，走溪沟”；
- 男主照着走。

**问题：没有交易、没有验证、没有代价。** 老K不是人物，是作者用来递信息的工具。

#### 第3章《拆骨》

- 杀铁壳蜥；
- 老K私聊“驿站收兽筋，十二星币一根”；
- 男主得到价格信息。

**问题：信息再次白送。** 男主的“会算”没有付出成本，读者也不会觉得他聪明，只会觉得作者在帮他。

#### 第7章《第一道门》

- 世界频道三条免费信息；
- 试炼规则、区域情况、门的位置，一次性倒给读者。

**问题：信息过载，生存孤立感被破坏。** 一个刚落地几天的人，不应该知道整个星区的情况。

#### 第4—27章

生存循环重复：找水、生火、交易、试炼、受伤、再找水。每个环节单看都真实，但连起来缺少“新生态、新生物、新规则”的探索感。读者记不住一个新物种，只记得男主一直在赶路。

#### 第28—33章 救女主

这是当前大纲里最值得保留的部分。蚀族缺水，抓“能听”的向导；女主故意带错路拖延；男主观察营地、换班、水源，夜里动手。这个原型是好的。

但当前写法缺了前半段：

- 男主为什么发现蚀族？
- 他为什么决定跟？
- 他凭什么判断自己打得过/打不过？
- 他准备了什么？
- 他付出了什么代价？

当前是“区域频道刷出蚀族押俘，他决定跟过去看”。**信息来得太容易，决定就显得轻。**

#### 第52—75章 北进会/门位/排队

这一段社会层过重：

- 北进会；
- 门位；
- 排队号；
- 入会；
- 悬赏；
- 契约。

生存文变成了“排队文/公会文”。读者来看的是“一个人在陌生生态里怎么活、怎么变强、怎么救出同伴”，不是“怎么在营地门口排队”。

### 1.4 生成链路的放大效应

| 层级 | 当前做法 | 问题 | 应改成 |
|---|---|---|---|
| 蓝图层 | keyEvents压缩事件 | 缺因果、来源、信息 | 章节工作单 |
| 场景拆解层 | AI自由拆3—5场 | 作者意图丢失 | 作者锁定场景卡 |
| 写稿层 | 场景卡只有目标/冲突/转折 | AI用套话补空 | 增加进出状态、信息表、禁区 |
| 审稿层 | 主要查词句 | 不查因果、来源、信息 | 增加结构审稿 |
| 未来蓝图 | 注入后3章 | 提前消费剧情 | 改为“后续剧情禁区” |

**结论：不是模型不行，是章纲没有把该锁的东西锁住。** 你越是用“4场景/3000字/每场700字”这种数字去约束它，它越会为了凑数而编；你越是用“来源/状态/信息/禁区”去约束它，它越不敢乱编。

## 2. 网络标准章纲给我们的启发

### 2.1 中文网文常用的“七问章纲”

常见的章纲格式是：

> 谁 + 在哪 + 目标 + 阻碍 + 转折 + 结果 + 钩子

这个格式比当前的“目标/冲突/转折”多两样东西：**结果**和**钩子**。

- 目标：他这一章想干什么？
- 阻碍：谁/什么拦着他？
- 转折：发生了什么变化？
- 结果：成功还是失败？得到或失去什么？
- 钩子：结尾留什么悬念？

当前章纲有前三项，缺后两项。所以每一章都像“开始了，但没有落地”。

### 2.2 四场景拆分法

常见做法是把一章拆成4个场景，每个场景写：

> 地点 + 人物目标 + 阻碍 + 信息变化 + 场景末钩子

注意“信息变化”这一项。它问的不是“发生了什么”，而是“这一场之后，谁知道了什么”。

- 男主知道了水源在哪；
- 读者知道了蚀族在押人；
- 对手知道了男主在跟踪；
- 女主知道了男主在附近。

**信息变化才是场景的真正推进。** 没有信息变化的场景，就是废场景。

### 2.3 黄金前三章

网文常见的“黄金前三章”不是三章都打脸，而是三章内让读者知道三件事：

1. 这本书的世界是什么规则；
2. 主角是什么人、想要什么；
3. 这本书的看点是什么（升级？求生？复仇？种田？）。

对应到本书：

- 第1章：世界规则（全民投放、极点目标、四格面板、交易面板）+ 主角性格（先拿水、不拿钱、不争一口气）；
- 第2章：生存规则（水、火、庇护所、危险）+ 主角处境（一个人、没有外挂、没有队友）；
- 第3章：第一个小胜（找到水/生起火/杀死第一头小兽）+ 第一个代价（消耗、受伤、暴露位置）。

### 2.4 十章一爽点，三十章一高潮

这是连载文的常见节奏。不是每章都要爆，而是：

- 每1—3章有一个小胜/小反转；
- 每10章左右有一个明确的“爽点”（第一次试炼通关、第一次交易赚到、第一次救下人）；
- 每30章左右有一个卷级高潮（第一座门、第一次越档、第一次生死战）。

当前章纲的问题不是没有高潮，而是高潮被大量“排队/入会/门位/悬赏”稀释了。

### 2.5 番茄向的节奏参考

番茄向作品常见的经验是：

- 单章2200—2800字更适合移动端阅读；
- 情绪曲线按“压—小扬—压—爆”循环；
- 开篇300字内必须有钩子；
- 每章结尾必须让读者想点下一章。

本书是冷硬求生，不必追求“每章打脸”，但“压—小扬—压—爆”可以借用：

- 压：缺水/受伤/被跟踪；
- 小扬：找到水/修好工具/完成交易；
- 压：水被污染/买家压价/异族出现；
- 爆：第一次猎杀/第一次试炼/救出女主。

### 2.6 西方 Scene/Sequel 结构

西方写作教学里有一个很实用的“场景—后续”结构：

**场景（Scene）：Goal → Conflict → Disaster**

- 目标；
- 冲突；
- 灾难性结果（不一定是大灾难，而是“情况变了，不能按原计划走”）。

**后续（Sequel）：Reaction → Dilemma → Decision**

- 反应：角色对结果的情绪/身体反应；
- 困境：他有哪些选择，各自代价是什么；
- 决定：他选一个，产生下一个目标。

这个结构正好补上当前章纲最缺的两块：

- 场景结束后的“结果”；
- 结果之后的“选择”。

### 2.7 Save the Cat 的卷级节拍

卷级结构可以参考 Save the Cat 的15拍：

> 开场画面 → 主题陈述 → 铺垫 → 催化剂 → 争论 → 进入第二幕 → B故事 → 游戏与乐趣 → 中点 → 坏人逼近 → 一切失去 → 灵魂黑夜 → 进入第三幕 → 结局 → 终场画面

不需要照搬，但可以用它检查第一卷：

- 开场画面：最后三分钟，日常被系统打断；
- 催化剂：投放；
- 争论：要不要进试炼、要不要救人；
- 进入第二幕：第一次试炼/第一次交易；
- 中点：救出女主，双人同行；
- 坏人逼近：掠夺者/蚀族猎队/资源危机；
- 一切失去：第一座门前的失败/代价；
- 结局：过门，进入新区域。

### 2.8 对本书的取舍

本书不追求“每章打脸”，所以不能照搬“装逼—打脸—反转”的爽文节拍。本书的爽点应该是：

- 他算得准：提前准备，躲过一劫；
- 他忍得住：不争一口气，保住命；
- 他付得起：每次胜利都有代价，但代价在可控范围；
- 他走得远：每过几章，他就多一件工具、多一条信息、多一个选择。

**章纲要写“可拍出来的动作”，不写“他很紧张/他判断/他决定”。** 这是反AI味的第一条。

### 2.9 几种章纲格式的对比

| 格式 | 核心字段 | 能解决什么 | 缺什么 |
|---|---|---|---|
| 当前平台格式 | 章号、标题、角色、目的、关键事件、人物、钩子、场景（goal/conflict/turn/props） | 事件推进、基本场景方向 | 结果、代价、信息差、物品来源、进出状态、禁区 |
| 网文七问 | 谁、在哪、目标、阻碍、转折、结果、钩子 | 单章因果完整 | 信息释放、物品账、场景状态 |
| 四场景法 | 地点、目标、阻碍、信息变化、场景末钩子 | 场景推进、信息变化 | 章级选择、代价、物品来源 |
| Scene/Sequel | Goal→Conflict→Disaster；Reaction→Dilemma→Decision | 场景与后续的因果衔接 | 网文章末钩子、中文语境 |
| 本报告新模板 | 章节工作单 + 场景卡 + 信息释放表 + 物品账 + 禁区清单 | 因果、状态、信息、来源、节奏 | 需要作者先定因果，不能交给AI自由拆 |

结论：**当前平台的格式不是“标准章纲”，而是“半成品场景卡”。** 它有三要素，但缺结果、代价、信息、来源、状态、禁区。补上这六样，才是一张能直接生成正文的章纲。

## 3. 新章纲体系：四层结构

### 3.1 总览

```
卷级节拍表（1页/卷）
  └─ 章节工作单（1页/章）
       └─ 场景卡（2—5张/章）
            └─ 禁区清单（1页/章）
```

这四层分别解决四个问题：

| 层级 | 解决的问题 |
|---|---|
| 卷级节拍表 | 这一卷为什么存在？从哪里到哪里？ |
| 章节工作单 | 这一章为什么必须写？主角做了什么选择？ |
| 场景卡 | 这一场谁想要什么？怎么受阻？结束时什么变了？ |
| 禁区清单 | 这一章不能出现什么？不能提前透露什么？ |

### 3.3 章节工作单模板

这是每章的核心工作单，建议一页纸写完。字段如下：

```
  女主新知道：
  对手新知道：
  禁止提前知道：
【物品账】
  来源：
  消耗：

  丢失：
【场景卡】2—5张（见3.4）
【伏笔】埋什么、回收什么、保留什么

```

```
【伏笔】兽径（第4章猎物）；雨水收集（第3章水源）；肩带撕裂（第8章交易换背包）
【章末钩子】危机：黑暗里有东西踩断树枝，停在棚外；他握住菜刀，不敢呼吸
```

### 3.4 场景卡模板

每张场景卡写清“进入—目标—阻力—转折—退出”：

```
场景N｜标题｜约X字

地点：

在场人物：

```

```
时间：系统公告后0:00—3:00
在场人物：商临野、店员、抢购人群、门外路人
```

### 3.5 章型与节奏

不要所有章节都3000字、4场景。建议按章型分档（字数可按平台闸门微调）：

| 章型 | 场景数 | 建议字数 | 必备要素 | 常见错误 |
|---|---:|---:|---|---|
| 建置章 | 2—3 | 3000—3400 | 新地点、新规则、新目标 | 信息倾倒、面板说明书 |
| 生存章 | 3 | 2800—3200 | 水/食/火/宿/警戒至少两项 | 流水账、重复受伤 |
| 试炼章 | 4 | 3200—3800 | 入场、规则显现、危机、结算 | 系统教程、无代价通关 |
| 关系章 | 3 | 3000—3400 | 共同决策、代价、信任变化 | 靠对话解释关系 |
| 高潮章 | 5 | 3600—4200 | 目标、阻碍、失败、反转、代价 | 无代价胜利、主角光环 |
| 过渡章 | 2 | 2400—2800 | 赶路/休整+一个新信息 | 纯水文、无状态变化 |

### 3.6 反模板化规则

1. **场景卡的目标/冲突/转折必须写成“具体动作+对象+结果”。**
   - 不写“他找水”。
   - 写“他在太阳落山前顺着兽径找到水坑，但水坑边有新鲜爪印”。
2. **禁止在章纲里写抽象判断。**
   - 不写“他判断值不值得”。
   - 写“他算了一下：绕路多走半天，但能避开营地；他选择绕路”。
3. **建立“章纲套话黑名单”。**
   - 只认看得见的东西；
   - 把时间掐在天黑前；
   - 数字对上了；
   - 他没再犹豫；
   - 先算；
   - 剩下的路得省着走；
   - 伤口还在渗血；
   - 护甲扣子又掉了一颗；
   - 背包比昨天轻了一斤；
   - 他没再说话。
   这些句子在章纲阶段就禁止出现。正文里出现一次可以，连续出现就是模板。
4. **每章至少一个“本章专属细节”。**
   - 一个新物种；
   - 一个新地形；
   - 一个新器物；
   - 一个新习俗；
   - 一个新谎言。
   没有专属细节的章节，就是可替换的章节。
5. **场景卡锁定后，AI不得增删场景、人物、顺序。**
   AI只能在场景卡内扩写镜头、对话、感官，不得新增“老K突然私聊”“系统突然解释”“路人突然送装备”。
6. **未来蓝图只作为禁区清单，不作为写作参考。**
   写第N章时，只告诉模型“第N+1到N+3章会发生什么，所以本章不能碰”，不告诉它“你可以顺着写”。

### 3.7 信息释放表

信息释放表是解决“老K问题”和“世界频道问题”的关键。每章填一张：

| 角色 | 本章新知道 | 仍然不知道 | 禁止提前知道 |
|---|---|---|---|
| 读者 | 投放规则、四格面板、交易面板、主线目标 | 试炼何时开启、附近有没有人、女主在哪 | 老K、驿站、试炼颜色、蚀族营地 |
| 男主 | 自己只有一包物资、附近有兽、雨水能喝 | 方向、距离、其他人是否活着 | 试炼入口、女主位置 |
| 女主 | 无（未出场） | 男主存在 | 男主位置 |
| 对手 | 无 | 男主存在 | 男主位置 |
| 系统 | 全部 | — | — |

第8章“第一笔交易”的信息表可以是：

| 角色 | 本章新知道 | 仍然不知道 | 禁止提前知道 |
|---|---|---|---|
| 读者 | 交易面板能匿名挂单、系统抽成、成交后才解锁私聊 | 买家是谁、买家在哪、信息真假 | 黑潮、驿站、试炼颜色 |
| 男主 | 兽筋能换盐；买家只关心货，不关心人 | 买家为什么收兽筋 | 买家背后有没有队伍 |
| 匿名买家 | 男主有货、会验货、不废话 | 男主的位置 | 男主营地 |
| 系统 | 全部 | — | — |

**写章纲时先填这张表，再写场景。** 信息表填不出来，说明这一章的信息设计是空的。

## 4. 世界观与系统改造

### 4.1 删除全球/区域聊天，只留交易面板

这是本次改造最重要的设定调整。

#### 删除项

- 世界频道；
- 区域频道；
- 好友0/0；
- 频道额度；
- 频道公告；
- 频道里刷出来的剧情信息（蚀族押俘、寒潮、门的位置、兽王坐标）。

#### 保留项

只保留**交易面板**。它不是聊天频道，是一个“匿名市场”：

- 挂单：卖东西；
- 求购：买东西；
- 商品详情：名称、数量、成色、要价/换什么；
- 商品留言：只能问与商品有关的问题，公开可见；
- 成交后：系统担保、抽成、评价；
- 成交后：双方解锁“私聊”和“加好友”；
- 未成交：不能加好友、不能私聊，只能通过商品留言/系统模板询价。

#### 交易面板规则（建议写入规则区）

1. 匿名挂单，系统担保，成交后抽取5%。
2. 挂单72小时自动下架。
3. 商品描述禁止出现坐标、联系方式、外部链接、虚假信息。
4. 违规商品下架，扣除信用分；信用分低的账号限制挂单。
5. 只有成交过的双方才能加好友、私聊。
6. 好友之间可以私聊，但不能群发、不能建频道、不能公开喊话。
7. 交易面板只连接本星/本投放区；跨区域交易走驿站/邮包，后期再开放。
8. 系统不提供“世界行情”，只提供本区当前挂单。

#### 信息载体五种

删掉聊天频道后，信息不能凭空出现。所有信息必须通过以下五种载体之一：

| 载体 | 能提供什么 | 例子 |
|---|---|---|
| 交易面板 | 供需、价格、稀缺度、求购 | 水价暴涨=附近缺水；有人高价收兽筋=驿站有需求 |
| 告示/价目表/界桩 | 规则、路线、危险提示 | 驿站木牌：“北坡夜雾，勿走溪沟” |
| 人嘴 | 情报、谎言、传闻 | 幸存者说“东边有水源”，可能是真的，也可能是调虎离山 |
| 环境 | 生态、危险、痕迹 | 新鲜爪印、被踩倒的草、空水罐、乌鸦盘旋 |
| 系统 | 目标、规则、结算 | “主线目标：活下去，前往极点” |

**每一种信息都要有代价。** 交易面板要花钱/换物；人嘴要人情/交换；环境要观察/冒险；系统只在关键节点给一句话。

### 4.2 试炼系统改造

#### 激活条件

试炼入口不是落地就有，也不是第7天自动开教学关。建议改为“生存评估”：

- 找到稳定庇护所（能挡雨/防兽，连续住2晚）；
- 找到稳定水源（至少一次成功取水/净水）；
- 完成第一次本土生物猎杀（或成功抵御一次袭击）。

三项满足后，面板出现：

```
【试炼入口已开启】
【本月个人试炼次数：2/2】
```

#### 配额

- 每月2次单人试炼；
- 每月1日00:00重置；
- 不设固定窗口，随时可以在面板选择；
- 进入即消耗1次；
- 失败/主动退出也消耗；
- 未进入不消耗；
- 卷一不做团队场，女主加入后两人轮流进入，另一人守营地。

#### 试炼信息

第一次开启时，系统一次性给出以下信息，不通过聊天频道播报：

```
【试炼入口开启｜本月 2/2】
【匹配：第七星区·全部试炼星·同阶文明】
【目标：完成场内目标】
【奖励：属性点＋通关物｜失败：无】
【死亡：真实死亡】
【颜色：白黄蓝红紫金黑，越深越强】
```

男主看到后，用自己的话判断：

- 2/2，意味着这个月只能进两次；
- 失败也扣次数，不能随便试；
- 死了就是真死，不能拿命赌；
- 颜色越深越强，白门是唯一能碰的。

**系统只说规则，不解释规则。** 解释由男主的判断完成。

#### 卷一仅单人试炼

- 单人场：1人=1支标准小队，按1人重算难度，只结算1份奖励；
- 不做团队场、不做固定五人编制；
- 女主加入后，两人轮流进入，另一人守营地/看灰尾；
- 双人同场作为卷二以后的特殊门种，不在卷一出现。

#### 试炼奖励线

每场试炼必须解决一个具体的生存痛点，不能随机掉垃圾：

| 试炼 | 章节示例 | 奖励 | 解决的痛点 | 代价 |
|---|---|---|---|---|
| 第1次 | 6—7 | 自净水壶 T1 | 饮水 | 滤芯7天/耐久 |
| 第2次 | 17—18 | 耐潮火种盒 | 生火 | 需要燃料 |
| 第3次 | 23—24 | 轻量防兽帐篷 | 住宿/警戒 | 重/占负重 |
| 第4次 | 32—33 | 折叠工兵铲 | 搭建/挖掘 | 耐久 |
| 第5次 | 40—41 | 生命探测仪 | 预警 | 耗电 |

**每场试炼至少要满足两项：一个新规则、一个新威胁、一个生存工具、一个属性变化。** 否则这场试炼就是多余的。

#### 首试是否补足F

两种方案：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A. 快节奏 | 首试直接补足F | 快速进入力量幻想，读者爽 | 前5章生存铺垫显得多余，试炼稀缺感下降 |
| B. 慢节奏（推荐） | 首试只给少量属性，F在第3—4次试炼后达成 | 生存期更长，试炼更有分量 | 前期升级慢，需要靠生态/器物/关系撑住 |

按你这次“前期偏生存向”的要求，建议选B。首试不是“补足F”的仪式，而是“第一次知道试炼是什么”的体验。

### 4.3 面板改造

#### 落地首次四格面板

按你的要求，固定面板四样：属性、装备、道具卡、技能。没有的写“无”。

```
【属性】商临野｜未入流｜力4｜敏4｜体4｜心识17
【装备】主手：无｜护具：无｜背包：帆布包（民用）
【道具卡】无
【技能】无
```

说明：

- 系统只认它自己的装备/道具卡/技能；
- 男主从超市抢的水、面包、菜刀、打火机，不显示在面板里，因为它们是“普通物品”；
- 这正好让读者明白：系统不是万能背包，现实物资要自己背。
- 技能“结构视界”可以在第4章第一次猎杀时激活，面板从“无”变成“结构视界（未命名）”，给读者一个明确的成长节点。

#### 后续面板

- 只在有变化时显示；
- 不重复空槽；
- 交易面板不是固定面板，是男主主动点开的界面；
- 系统单句只给目标/规则/结算，不做世界观讲座。

### 4.4 物品来源规则

每件物品第一次出现，必须能回答“哪来的”。只允许三种来源：

1. **自己带的**：符合人物身份，前文交代过。
2. **现场抢/买的**：写清动作、数量、代价。
3. **系统/试炼给的**：写清面板/结算/奖励来源。

#### 第1章超市可拿清单

| 类别 | 可拿 | 不建议拿 |
|---|---|---|
| 水 | 瓶装水、桶装水（太大）、饮料（不划算） | 含糖饮料、酒 |
| 食物 | 面包、压缩饼干、火腿肠、罐头 | 薯片、糖果（占地方、不顶饱） |
| 刀具 | 水果刀、菜刀、剪刀 | 军用水壶、伐木柴刀、工兵铲（无来源） |
| 火 | 打火机、火柴 | 喷枪、酒精（危险） |
| 遮蔽 | 塑料布、雨衣、胶带、绳子 | 帐篷（超市没有） |
| 其他 | 手电筒、电池、毛巾、创可贴 | 钱、烟、酒、化妆品 |

**“军用水壶、伐木柴刀、工兵铲”这类专业装备，在开篇没有来源，建议删除。** 如果后续需要，让他在驿站/试炼/黑市获得，并写清代价。

### 4.5 女主线：保留原型，强化因果

#### 保留的核心

- 蚀族缺水，需要“能听”的向导；
- 女主苏晚棠有“回声”能力，能听水/听脚步/听空腔；
- 她故意带错路，拖延时间，等救援；
- 男主北上途中遇到蚀族押俘；
- 两人合力逃脱；
- 之后双人同行，轮流试炼。

#### 需要补强的前因

当前写法是“区域频道刷出蚀族押俘，他决定跟过去看”。建议改为：

1. **发现痕迹**：男主在兽径上看到被踩倒的草、绳头、空水罐、赤脚脚印。
2. **判断成本**：他跟踪一段，发现对方有3—5人，自己打不过；但对方带着俘虏，走不快。
3. **观察营地**：他趴在芦苇里，看守卫换班、水槽位置、俘虏关在哪。
4. **准备**：他回去拿绳子/火/刀，用交易面板换一件必要的工具。
5. **行动**：不是正面冲，而是割绳/放水/制造混乱。
6. **女主自救**：她已经磨断一半绳子，不是完全被动。
7. **代价**：男主受伤/丢装备/被追；女主使用能力后耳鸣，行动受限。
8. **信任**：救出后不立刻组队，签“同路契约”：随时能走、物资各带各的、救命的账另算。

#### 删除

- 英雄救美式单方面拯救；
- 救出后立刻信任、立刻组队；
- 女主只会被救、没有自救；
- 女主的能力没有代价、当万能雷达。

### 4.6 老K的处理：前期删除，黑潮后再引入

结论：**卷一前期不出现老K，也不出现任何“开局送信息”的角色。**

原因不是“老K这个角色不好”，而是时间点不对：

- 刚落地时，所有人都没有稳定物资，也没有可靠信息；
- 没有东西可卖，也没有钱可付，信息中间人没有交易基础；
- 男主自己都还没搞清楚水源、兽径、方向，别人不可能比他多知道一个量级；
- 这时候出现一个“什么都知道、什么都免费说”的人，读者第一反应不是“幸运”，是“作者在帮他”。

老K的重新定位：

- **登场时机**：黑潮线启动之后。南边开始有难民往北走，有人需要知道“黑潮到哪了、哪条路还能走、哪座门快关了”。
- **交易内容**：黑潮推进速度、被吞区域、难民路线、门位拥挤程度、哪段路已经不能走。
- **交易方式**：只在交易面板挂单，匿名ID，系统担保；成交后才解锁私聊。
- **信息性质**：半真半假，有滞后，有区域偏差；他能赚，是因为他比别人早走一步，不是因为他是系统NPC。
- **关系推进**：第一次交易只买一条；第二次验证；第三次才可能加好友。信任是买出来的，不是聊出来的。

卷一只需要保留“匿名交易”这个功能，不需要给交易对象起名字。第8章的第一笔交易，买家就是一个没有名字的匿名ID；成交、收货、结束，不寒暄，不加好友。

## 5. 第1章逐场重写示范

### 5.1 设计原则

1. **先日常，再异常。** 先让读者看到一个普通人的普通夜晚，再让系统打断它。
2. **先公告，再政府，再混乱。** 政府播报不是背景音，它是恐慌的触发器：它证明系统不是恶作剧，而且官方也没有办法。
3. **三分钟不是背景板，是本章的核心倒计时。** 每一个动作都要消耗时间，每一个选择都要放弃另一样东西。
4. **商店抢购是人物第一次展示能力。** 不是打架，而是知道拿什么、放弃什么。
5. **落地后不急着打怪。** 先给陌生环境、四格面板、交易面板、主线目标，让读者和男主一起“懵”三秒。
6. **章末钩子必须是具体的危机/决定/信息。** 不写“他知道，真正的考验开始了”这种总结。

### 5.2 章节工作单

```
【地点】东陆联邦·城中村24小时便利店 → 低纬区·赤道雨林
【承接】无（开篇）

【关键选择】水/食物/刀/火/塑料布，只能拿一部分；他选择“水+食物+刀+火+塑料布”，放弃“更多食物、钱、烟酒、别人的包”
```

### 5.3 场景1：日常与公告（约700字）

**地点**：城中村24小时便利店。凌晨一点，雨。男主值夜班，正在把过期盒饭按时间贴标，背包放在收银台下面。电视挂在墙角，声音很小。手机放在台面上，屏幕裂了一角。

**日常细节**（3—4个动作，建立人物）：

- 他把找零的硬币按面值码好，五毛一摞，一块一摞。
- 他把临期饭团贴上半价标签，贴歪了，又撕下来重贴。
- 他看了一眼手机：没有新消息。屏幕上是上个月的工资条。
- 外面雨很大，玻璃门上贴着一张“招聘夜班”的纸，边角卷起来。
- 背包是他自己的，旧帆布包，里面有一副线手套、一卷胶带、一把美工刀、一件折叠雨衣。他平时接零工，工具习惯随身带。

**异常**：

1. 所有屏幕同时黑了一下。电视、手机、收银机、门口的广告灯牌，全黑。
2. 男主眼前弹出一块半透明的面板，白底黑字，没有边框：
   ```
   【全民求生协议已启动】
   【三分钟后，全体人类将被投放至墟星，参与文明试炼】
   ```
   街上的人面前也弹出同样的面板。有人伸手去摸，有人往后退，有人拿手机对着面板拍。
3. 天空出现光柱。不是一道，是很多道，从云层里垂下来，落在街道、楼顶、远处的高架桥上。每一道光柱落地的地方，雨都被蒸成白雾。
4. 公告重复第二遍。街上有人笑，说“哪个傻逼搞的AR特效”；有人拿出手机拍；有人站在原地不敢动。
5. 公告重复第三遍。笑声没了。远处传来刹车声、喇叭声、玻璃碎裂声。
6. 政府紧急播报插进来。电视画面切到蓝底白字，一个没有露脸的声音：
   > “市民朋友们，请保持冷静。不要靠近光柱，不要触摸不明面板，等待官方进一步通知……”
   门外的高音喇叭也在响，和电视里的声音差半拍。店长的电话打进来，男主接了，店长只说了一句“你看店，我过去看看”，然后就没声了。
7. 人群开始乱。有人往外跑，有人往货架里钻，有人抱着孩子站在雨里哭。

**男主的反应**：

- 他没有拍视频，也没有给谁打电话。他看了一眼面板上的倒计时：02:59。
- 他看了一眼门外：最近的光柱在街对面，离店门不到五十米。
- 他看了一眼货架：水在最里面那排，面包在收银台旁边，刀在日杂区，后仓有塑料布和绳子。
- 他算了一下：回家来不及，去防空洞来不及，留在这里等政府也来不及。三分钟，够他把这间店搬空一小半。
- 他抓起背包，跨过收银台。

**场景末**：他冲进货架间，肩膀撞倒一排口香糖。倒计时 02:47。

**禁止**：不要写“他想起实验室”“他想起导师”“他发誓要活下去”；不要写“全球直播”“弹幕”；不要写系统解释“什么是文明试炼”；不要写电影化的慢镜头。

### 5.4 场景2：三分钟抢购（约900字）

**地点**：社区超市货架区 + 后仓。**时间**：02:47—00:00。

**时间节点与动作**：

- **02:47**：他先拿水。货架最外侧的两瓶1.5L矿泉水，塞进背包主仓。第三瓶被人从侧面撞掉，滚到地上，他没捡。
- **02:31**：食物。三袋面包、两包压缩饼干、一根火腿肠。薯片、饮料、酒，他看了一眼，没拿——占地方，不顶饱。
- **02:12**：刀。水果刀在日杂货架最下层，他蹲下去拿，手指被包装塑料划了一下。菜刀在后仓，他绕过抢水的人群，从员工通道进去。
- **01:48**：后仓。菜刀插在腰上，打火机塞进裤兜，一卷塑料布夹在包外，一截尼龙绳绕在肩上。他看到一箱没开封的水，但背包塞不下，只拿了两瓶。
- **01:20**：有人拽他的包。他转身，用肩膀撞开对方。对方骂了一句，伸手再抓，他抬脚踹在货架腿上，货架晃了一下，对方退了一步。他没回头，肩带“嗤”地撕裂。
- **00:52**：他跑回店堂。玻璃门自动锁死，外面的人拍门，里面的人砸门。他绕到员工通道，用菜刀别开门缝，侧身挤出去。
- **00:21**：白光从街对面压过来。雨滴停在半空，声音消失。他抓住背包带，手指被刀背划了一下。
- **00:03**：他回头看了一眼——店里还有人，站在货架前，抱着一堆东西，动不了。
- **00:00**：白光吞没街道。失重、耳鸣、黑。

**人物选择**：

- 他不抢钱。收银台抽屉开着，里面有一沓现金，他没看第二眼。
- 他不抢烟酒。那些东西在末日初期可能能换东西，但太重，而且他现在需要的是水和食物。
- 他不跟人打架。有人抢他的水，他让；有人拽他的包，他撞开就走；他不追、不骂、不回头。
- 他拿的东西都有明确用途：水（喝）、食物（吃）、刀（防身/处理猎物）、火（生火）、塑料布（庇护所）、绳子（捆绑/搭棚）。

**场景末**：白光里，他最后的感觉是背包带勒进肩膀，菜刀硌着腰。

**禁止**：不许写“他大杀四方”；不许写“他抢了收银台的钱”；不许写“他救了一个小孩/老人”（第1章不展开支线）；不许写“系统提示他拿了什么”；不许写“瞬间”“死死”。

### 5.5 场景3：落地与四格面板（约800字）

**地点**：低纬区·赤道雨林边缘。**时间**：第1天，清晨/上午（时间流速不同，他自己也说不清）。

**落地**：

- 先是泥。脸贴在泥里，嘴里全是土腥味。他撑起来，膝盖陷进泥里，拔出来时带出一声“啵”。
- 雨还在下，但比现实里的雨更热。衣服贴在身上，分不清是雨还是汗。
- 他先摸腰：菜刀还在。再摸背：背包还在，肩带断了半根。再摸口袋：打火机还在。
- 他检查身体：手指上有一道浅口子，膝盖磕了一下，走路不受影响。**伤情一笔带过，不渲染。**

**环境**（新生态，不要废土滤镜）：

- 树很高，树干上长着气根，像一层层垂下来的绳子。
- 地上的蕨类叶子比人还高，叶背有淡蓝色的孢子，手一碰就合上。
- 泥里有六条腿的小虫，跑得很快，停下来时像一粒会动的黑豆。
- 远处有声音，不是鸟叫，是某种低沉的、从喉咙里挤出来的震动。
- 他看到泥里有一串脚印，三趾，比他的脚掌大一圈，边缘还没塌——是刚踩的。

**四格面板**：

```
【属性】商临野｜未入流｜力4｜敏4｜体4｜心识17
【装备】主手：无｜护具：无｜背包：帆布包（民用）
【道具卡】无
【技能】无
```

**男主的反应**：

- 他盯着“装备：无”看了两秒，又看了看腰上的菜刀。
- 他试着把菜刀举到面板前，面板没反应。把打火机放上去，也没反应。
- 他明白了：面板不认这些东西。它只认它自己的装备、道具卡、技能。
- 他清点背包：半瓶水（另一瓶在店里掉了）、三袋面包/饼干、水果刀、菜刀、打火机、塑料布、尼龙绳。肩带用绳子临时绑住。
- 他没有急着走。他蹲下来，听了一会儿，确认那串三趾脚印是往外走的，不是往他这边来的。

**场景末**：他顺着脚印的反方向，往地势高的一侧走。雨小了一点，天还是灰的。

**禁止**：不许写“他发现自己穿越了/重生了”；不许写“他想起七年前”；不许写系统解释“这是墟星”；不许写“空气中弥漫着……”；不许写“阴冷/潮湿/斑驳/腐朽/破败/荒凉/死寂/灰败/狰狞/黏腻”这类废土滤镜词。

### 5.6 场景4：交易面板与主线目标（约600字）

**地点**：雨林边缘·一处倒木下的凹地。**时间**：第1天，傍晚。

**交易面板**：

- 他刚把塑料布从包里抽出来，眼前又弹出一块面板。这次是交易面板，灰底，三行字：

```
【本区交易行】
【当前挂单：0】
【规则：匿名挂单 · 系统担保 · 成交抽成5% · 72小时下架】
```

- 面板下方有两个空栏：“我要买”“我要卖”。
- 他点了“我要卖”，里面只有一个输入框：物品、数量、要价/换什么。
- 他没有东西可卖。水要喝，食物要吃，刀要防身。
- 他点了“我要买”，里面是空的。整个区，没有一个人在卖东西。
- 他注意到面板角落有一行小字：“成交后可私聊/加好友。”没有世界频道，没有区域频道，没有在线人数。
- 他关掉面板。雨落在塑料布上，噼啪响。

**主线目标**：

- 他刚把塑料布四个角用绳子绑在倒木上，面板又亮了一下。这次只有一行字：

```
【主线目标：活下去，前往极点，完成最终考验】
```

- 没有解释，没有箭头，没有距离，没有奖励说明。
- 他看着那行字，看了很久。然后他低头，把最后半瓶水拧开，喝了一小口。

**第一夜**：

- 他没有生火。湿柴不好点，烟会引来东西。
- 他吃了半袋面包，把菜刀放在右手边，背包垫在背后。
- 塑料布外面，雨声、虫声、远处某种东西踩断树枝的声音。
- 他握住刀，没动。

**章末钩子**：

黑暗里，那个声音停在棚外。很近。他能听到对方呼吸，或者只是风。他不敢呼吸，手指收紧刀柄。

**禁止**：不许写“他知道，真正的考验开始了”；不许写“他发誓要走到极点”；不许写系统解释“极点是什么”；不许写“他想起过去/家人/导师”；不许写“他笑了/他哭了”。

## 8. 验收清单

每章定稿前，逐项打勾：

### 结构

- [ ] 本章有一个具体的、可验证的欲望（不是“变强/活下去”这种大词）。
- [ ] 有一个具体的阻力（谁/什么，为什么现在）。
- [ ] 有一个不可两全的选择（A还是B，各自代价）。
- [ ] 有一个明确的结果（成功/失败/部分成功）。
- [ ] 有一个明确的代价（资源/关系/伤口/机会/信息）。
- [ ] 本章结束时，主角的位置/资源/关系/信息/能力至少一项发生变化。

### 物品与数值

- [ ] 每件新物品都有来源（自己带的/现场抢的/系统给的）。
- [ ] 每件消耗品都有数量变化（水/食物/火/药/绳子）。
- [ ] 负重/距离/时间能对上。
- [ ] 没有“军用水壶/伐木柴刀/工兵铲”这类无来源专业装备。

### 信息

- [ ] 每条新信息都有载体（交易面板/告示/人嘴/环境/系统）。
- [ ] 每条新信息都有说者、动机、真假。
- [ ] 男主知道的信息不超过信息释放表。
- [ ] 没有世界频道/区域频道/好友0/0。
- [ ] 没有提前透露后续3章的人/事/物。

### 场景

- [ ] 场景卡没有被AI增删/改序。
- [ ] 每场都有进入状态和退出状态。
- [ ] 每场都有信息变化或物品变化，不是纯过场。
- [ ] 环境描写没有超过配额。
- [ ] 没有套话黑名单里的句子。

### 文风

- [ ] 没有“瞬间/死死”。
- [ ] 没有“他想起过去/家人/导师/实验室”。
- [ ] 没有“他发誓/他笑了/他哭了/他知道真正的考验开始了”。
- [ ] 没有电影化夸张动作。
- [ ] 没有废土滤镜词堆砌。
- [ ] 段落长度符合平台要求。
- [ ] 章末钩子是具体的危机/信息/决定，不是总结。

### 节奏

- [ ] 本章属于明确的章型（建置/生存/试炼/关系/高潮/过渡）。
- [ ] 本章至少有一个“本章专属细节”（新物种/新地形/新器物/新习俗/新谎言）。
- [ ] 每3—5章有一个新生态细节。
- [ ] 每10章左右有一个小爽点。
- [ ] 每30章左右有一个卷级高潮。

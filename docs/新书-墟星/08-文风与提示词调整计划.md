## 1. 目标口径（一页标准，执行后写进 05）

**一句话文风**：冷硬、具体、有代价的求生文——先给可验证的物理事实，再给判断；不抒情、不解释系统、不让角色白赢。

**零容忍（出现即 error）**：哲理对举 / 破折号抒情 / 生理替代情绪 / 空洞收尾 / 形容词三连 / 无意义精确数字 / 公文腔 / 跨体系意象 / 环境三层感官公式 / "轰"与"百丈" / 套路化身体反应 / 章末升华。

**配额（超限即 warning）**：比喻 ≤2/千字；体感描写 ≤3/段；连续描写 ≤2 句；同一动作 ≤2 次/章；同一数字 ≤1 次/段；面板 ≤2 次/章、≤5 行；气味 ≤2 处/章；废土滤镜词 ≤2 次/章。

**词表**：禁用（06 A/B/C 全量）→ 慎用（瞬间、顿时、猛地各 ≤3/章）→ 替换（眸子→眼睛、仿佛→删、心中一凛→手停住…）。

## 8.4 第四轮：伤口与疼痛复述（2026-11-05）

### 8.4.1 问题定性

用户原句：

> 左肩的创口被粗布死死勒住，每一次摆臂，凝固的皮肉就扯动神经，传来阵阵钝痛。

它“看起来不像 AI”，是因为没有形容词堆叠、没有抒情；但它仍是模板，结构固定为：

**伤口外观（被布条勒住）→ 每一次动作 → 解剖词（皮肉/神经）→ 疼痛词（阵阵钝痛）**

四件事都在重复同一个信息“他受伤了”，没有一件改变动作或决定。这类句子不是词表问题，词表拦不住，必须按**句式**拦。

### 8.4.2 教程与热门小说的共同结论

| 来源 | 结论 |
|---|---|
| Writers Helping Writers《How To Accurately Write About a Character's Pain》 | 疼痛提醒读者只有三种方式：直接写疼、写“绕开疼”、写疼的代价；**直接写疼应尽量少**，多数篇幅应写后两种 |
| Descriptionary《Writing Injuries: The Art of Appropriate Scaling》 | 伤必须持续影响行动，不能下一场景消失；影响要落在**动作限制**上，不是反复报疼 |
| Adazing / Grammar Gamma / The Little Bookish | 具体化优先；避免通用疼痛词堆叠与连续疼痛描写；一个细节写透胜过三个形容词 |
| 阅文作家专区（痛感描写） | “四肢百骸”“钻心”式陈词会让读者**不疼了**；应按皮肉/内脏/神经分层，一次只写一层 |
| 中文白描范例（断臂） | “右手断了，伤口处一片殷红……”十二字，不修饰；克制的白话让后果自己说话 |

一句话：**伤口的功能是改变动作与选择，不是提醒读者“他受伤了”。**

### 8.4.3 新口径（四条）

1. **伤口只出现一次**：受伤当场写清来源与功能损失；伤口外观（翻卷/凝固/渗血/结痂/被布条勒住）全章只写 1 次。
2. **疼只报一次**，且必须改变动作或决定；报“做不到什么”（抬不过肩、握不紧、跑起来发空、喘气只到一半），不报“钝痛/抽痛/刺痛/阵阵”。
3. **之后只写绕开与代价**：换手、换肩、改握法、先迈好腿、把包挪到另一边；或慢半拍、失手、被对手抢到空档。
4. **禁止三种句式**：①「每一次/每回/每走一步/每抬一次手/只要…就…扯动/牵扯/传来…钝痛」；②「伤口/创口被…勒住/裹住/扎紧」后再接疼；③「皮肉/神经/甲床/骨膜」当痛源。也不得用「疼得直抽气/倒吸凉气/皱眉/脸色发白」替代疼。

### 8.4.5 改写示例

**反例**：左肩的创口被粗布死死勒住，每一次摆臂，凝固的皮肉就扯动神经，传来阵阵钝痛。
**正例**：左肩缠了布条。他把背包换到右肩，系带时用牙咬住一头。上坡到一半，左臂抬不起来，他侧身蹭着树根往上挪。

**反例**：他疼得倒吸一口凉气，扶着墙，每走一步都牵扯到伤口。
**正例**：下坡时他先迈右脚。左脚只跟半步。走到第三级，手从扶手上滑开，他改成坐下去，一级一级蹭。

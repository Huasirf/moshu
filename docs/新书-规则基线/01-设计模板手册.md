## 1. 等级体系

### 1.1 人物等阶

| 等阶 | 最高单项门槛 | 1/4 规则下的总和参考 | 定位 |
|---|---|---|---|
| 未入流 | <50 | — | 激活前 |
| F | 50 | 86 | 新人 |
| E | 300 | 525 | 低阶主力 |
| D | 600 | 1050 | 中阶门槛 |
| C | 1200 | 2100 | 分水岭 |
| B | 2400 | 4200 | 高阶 |
| A | 4800 | 8400 | 上位 |
| S | 10000 | 17500 | 顶层 |

规则：

1. 只按最高单项判阶，达线即晋阶；不设半步阶，不写"准 C""半步 B"。
2. 1/4 铁律：最低单项 ≥ floor(最高单项 ÷ 4)；不足时奖励点强制拆分补足。
3. 阶位加成：每跨一个大阶，四维各 +20%，只用于战斗，不计入下一阶门槛，不可剥夺，不占脑域。
4. 属性点不可存、不可自由分配；到账即按资质权重灌注，1/4 缺口优先。
5. 等阶认证按历史最高保留；扣点跌破门槛不掉阶，但战力按当前值算。
6. 属性转换只允许高→低，每次 50 点，转换后仍须满足 1/4。

### 1.2 装备等级

| 等级 | 判定口径 | 门槛 | 写法 |
|---|---|---|---|
| F | 固定属性项（逐项校验） | 50 | 力量 30 + 敏捷 20 = 50 |
| E | 固定属性项（逐项校验） | 300 | 力量 150 + 体魄 150 = 300 |
| D | 固定属性项（逐项校验） | 700 | 力量 400 + 体魄 300 = 700 |
| C | 总属性，首任首配 | 1300 | 首次穿戴前分配，总和 ≥1300 |
| B | 总属性，首任首配 | 2500 | 首次穿戴前分配，总和 ≥2500 |
| A | 总属性，首任首配 | 3600 | 首次穿戴前分配，总和 ≥3600 |
| S | 总属性，首任首配 | 5000 | 首次穿戴前分配，总和 ≥5000 |

规则：

1. F–D 必须在装备上写死 1–3 个具体属性项与各自数值，各项数值合计等于门槛（设计预算）；穿戴时逐项校验，每项都必须达到写死值，不得用其他属性凑数，无自分配，全书浮动不超过 ±10%。
2. C 以上只写总门槛；第一个获得者、装备崭新、首次使用前可分配一次归属，总和达标即可。
3. 首配只此一次，分配后永久固定；转手、借调、掉落都不重置。想改只能回炉重铸，且必须定价，不能写成免费洗点。
4. 首配分配的是"门槛归属"，不额外赠送属性点。
5. 装备门槛与人物等阶门槛是两套表，禁止互相套用。
6. 属性补位件也要满足同档门槛；它解决"差几点"，不解决"越阶"。
7. "无等阶要求"一律改称"总属性门槛型"，单列，不套用本表，且全书数量受限。

### 1.3 副本等级（颜色）

| 颜色 | 难度定位 | 推荐进入段 | 准入条件 | 单次属性上限 | 团队钥 |
|---|---|---|---|---|---|
| 白 | 入门 | F–E | 默认可用 | 4 | 有 |
| 黄 | 低阶 | F–E | 无门槛 | 8 | 无 |
| 蓝 | 中低 | F–E（该段上限） | 黄 5 次通关 | 15 | 无 |
| 红 | 中阶 | D–C | 蓝 5 次通关 | 20 | 无 |
| 紫 | 中高 | D–C、B–A–S（求稳） | 红 5 次通关 | 25 | 有 |
| 金 | 高阶 | B–A–S | 紫 5 次通关 | 50 | 有 |
| 黑 | 极阶 | 不列入推荐，搏命档 | 金 5 次通关 | 100 | 无 |

规则：

1. 副本等级 = 入场试炼卡颜色，不看人物等阶。
2. 同色副本的敌人、机关、时限按该色固定；高阶进低色场不会把副本抬高，只会更轻松，收益仍按低色上限。
3. 低阶进高色场不会降低难度，系统不提供保护；F 进红场，就是 F 打 C 场。
4. 颜色只代表难度与奖励，不是人物等级闸门；人物等阶只影响生存率。
5. 准入只看通关次数：白、黄无门槛；黄 5 → 蓝；蓝 5 → 红；红 5 → 紫；紫 5 → 金；金 5 → 黑。
6. 未取得准入时，可以持有、买卖该色试炼卡，但不能开启对应试炼。
7. 无首通加成、无团队倍率、无越档倍率；颜色上限就是单次属性点的硬顶。

### 1.4 试炼卡规则

| 项 | 口径 |
|---|---|
| 形态 | 巴掌大纯色卡片，无字、无号、无纹样、无芯片；同色不可区分 |
| 来源 | 只由试炼系统产出；蓝星不可制造、复制、改写，因此不存在假卡 |
| 性质 | 消耗品、不绑人、可交易、可赠送、可囤积、可抵押 |
| 消耗 | 入场即消耗；不入场不消耗 |
| 返还 | 成功通关高概率返还同色新卡，占结算奖励项之一，可能被更高价值奖励挤掉 |
| 失败 | 不返还，试炼卡直接损失 |
| 准入 | 只看同色通关次数，不看人物等阶 |
| 配额 | 单人每月 2 次 + 团队每月 1 次 = 月 3 次；配额按身份卡扣；交易试炼卡不占配额，入场才占 |
| 交易 | 官方长期收购、公开售卖紫及以下；金、黑不挂牌，只在黑市拍卖会与大家族流通 |
| 价格 | 各地区分别定价；官方收购价 < 本地黑市价 < 本地官方售价，不写死数值 |
| 死亡 | 随身携带的试炼卡随其他物品一并消失 |

## 2. 参赛规则

| 项 | 口径 |
|---|---|
| 资格 | 年满 18 周岁后第一个月内，凭本人身份卡到试炼厅免费领取 1 张白卡（成年礼），只查身份、不读卡、不登记，逾期视为放弃；18 岁前不可进试炼 |
| 匹配 | 个人按试炼卡颜色分池；团队按年龄段 + 卡色；人物等阶不作准入 |
| 配额 | 个人 2 次 + 团队 1 次 = 月 3 次 |
| 团队窗口 | 开启后 3 天内进入，当月完成，不可跨月筹备 |
| 团队指挥 | 必须唯一；临时/自由组队上限 3 人 |
| 死亡 | 随身装备、技能、饰品、伴生物、道具卡、试炼卡全部消失，不可继承 |
| 退出 | 非死亡型可退，判失败，扣最高项 20 点 |
| 失败扣点 | 普通 20 / 防御 30 / 死战 50；战绩越高扣得越少 |
| 惩罚延后 | 可延后至次月结算，面板须标"待结算惩罚" |
| 优先级链 | 试炼强制规则 ＞ 关卡特殊规则 ＞ S 级技能/死契 ＞ 常规装备技能 ＞ 生态惯例 |

补充：

1. 年龄限制单向：只限制更高年龄段，低年龄段可助力、可跨段挑战。
2. 团队按年龄段匹配，不按实力；带高龄或高阶队员会抬高档位、放大难度。
3. 异族寿命差异由规则自动校正；差距过大或跨区种族一般不相遇。
4. 团队场只有白、紫、金三色试炼卡；人数建议白 ≤5、紫 ≤5、金 ≤20，待定。
5. 团队场属性点按同色上限，每人一份，无倍率；团队收益只体现在掉落品质、材料与情报。

## 3. 装备设计模板

### 3.1 必填字段

| 字段 | 规范 | 易错点 |
|---|---|---|
| 名称 | 具体器物名，全书不重名 | 禁用"XX之刃"批量命名；反差名全书 ≤2–3 个 |
| 等级 | F/E/D/C/B/A/S，可叠"总属性门槛型" | 只标等级不标数值＝空条 |
| 类型/部位 | 武器/盾/甲胄/头盔/面具/护臂/护腿/鞋/饰品/特殊；盾占武器位 | 多盾须放弃其它部位 |
| 属性要求 | F–D 固定属性项、逐项校验；C 以上首用分配 | 两套口径不可混用 |
| 基础数值 | 焦耳制攻/防/承伤，按档给 | 不随等级无限加零 |
| 完好度 | 0–100，归零爆；单场损耗 5–20 点 | 与耐久混写 |
| 耐久度 | 0–100，归零禁用不毁 | 同上 |
| 词条数 | F–D 2–3；C/B 4；A 5 选 3；S 5+体系 | 超额即破坏配额 |
| 触发方式 | 永久/战斗/手持/外力/受击叠层/濒死/蓄层 | 同类被动不叠加 |
| 冷却 | 秒→分→时→天→月，必须确定值 | 禁止"较长""较短" |
| 代价 | 绑定/占位/自减/环境/弃条，至少 1 条 | S 级至少 2 条 |
| 获取/修理/绑定 | 来源唯一可复述；箱档＋修理师等级；可交易/可借调/觉醒绑定/专属绑定 | 绑定件须强于同阶可交易件 |
| 隐性加成 | ≤5% 全属性，单独结算 | 不得进入装备/技能乘区 |
| 市价 | 按等级/词条/稀有度定价并标"约" | 与等级不匹配即失真 |

### 3.2 词条与数值区间

| 档位 | 单条属性点 | 单条百分比 | 词条数 | 典型冷却 |
|---|---|---|---|---|
| F | +3～8 | 3%～5% | 2–3 | 10～30 秒 |
| E | +8～15 | 5%～8% | 3 | 分钟～小时 |
| D | +15～25 | 8%～12% | 4 | 1～12 小时 |
| C | +20～30 | 10%～15% | 4 | 9～17 小时 |
| B | +25（固定锚点） | 10%～19% | 4–5 | 12 小时～月 3 次 |
| A | +30～50（推断） | 20% 起 | 5 选 3 | 13～18 小时 |
| S | 不给单条，给"资源"（层数/次数） | 30%～100% | 5+体系 | 3 天/月 3 次/5 年 |

### 3.3 设计要点

1. 先定场景再定槽位：常规 3 件、赛事 7 件、现实 8 部位，开篇报数。
2. 门槛要能被"补"：F–D 预留 ±30 点单项差；C 以上预留 100–200 总属性差，制造"买不买这件"的抉择。
3. 被动数值低、主动数值高；被动写永久，主动写窗口。
4. 每件装备至少一个"不可用场景"（须手持、须外力），逼角色取舍。
5. 词条要给"弃条"而非"全收"（五选三、四选二），让毕业装带遗憾。
6. 一件装备只讲一个故事；多功能堆叠会失去记忆点。

### 3.4 避免点

1. 槽位数字随手改，读者无法建立预期。
2. 同名不同档（"修理箱"给四套恢复量），紧张感归零。
3. 强词条只写加成、不写冷却与条件，同阶战斗被一件装备压塌。
4. 无上限叠层，后期只能不断加零。
5. 绑定只写"不可交易"、不写死亡损毁，绑定变免费增益。
6. 装备门槛混用两套口径，读者算不明白，配装失去博弈。

## 4. 技能设计模板

### 4.1 分级与脑域

| 档 | 脑域占用 | 典型冷却 | 持续 |
|---|---|---|---|
| F | 2%–3% | 10～30 秒 | 瞬发 |
| E | 5%（功能型 9%） | 90 秒～12 小时 | 瞬发～2 分钟 |
| D | 6% | 20 分钟～4 小时 | 30～120 秒 |
| C | 8%–10% | 9～17 小时 | 0.8 秒～30 分钟 |
| B | 10%–12%（推断） | 12～24 小时（推断） | 按条标定 |
| A | 门槛 13%（占用未记） | 13～18 小时 | 5 分钟 |
| S | 15%–16% | 3 天/月 3 次/5 年 | 即时～30 分钟～永久 |

### 4.2 必填字段

| 字段 | 说明 |
|---|---|
| tier | 技能等级，与学习等阶分开 |
| tier_req | 学习所需人物等阶 |
| attr_req | 单项属性门槛 |
| attr_total_req | 总属性门槛（如有） |
| brain_req | 脑域占用 |
| slot_req | 技能槽占用 |
| effect | 数值 / 持续 / 范围 / 目标 |
| cost | 脑域 / 体魄 / 属性点 / 心识 / 当前状态 % |
| cooldown | 确定冷却值 |
| side_effect | 反噬、环境限制、失败后果 |
| growth | 升级或专精后的变化 |
| panel_text | 面板写法 |
| source | 获取来源 |

### 4.3 学习四门槛

1. 等阶/属性门槛。
2. 脑域承载力。
3. 技能槽。
4. 前置条件（技能、装备、阵营、血契等）。

任一不足即不可学；脑域是硬闸，槽位是软条件。

### 4.4 S 级代价法则（至少勾两条）

1. 脑域 15%–16%，永久吃掉约 3 个技能位。
2. 死契排期：每 3 个月一场真死战，提前一个月提示，不可豁免。
3. 次数上限：一月 3 次 / 一生 1 次 / 5 年冷却。
4. 非必中与落空反噬。
5. 环境限定（仅阴暗 / 仅夜间 / 仅极深地带）。
6. 失败销毁（试用失败即技能消失）。
7. 规则边界：S 级默认不能跨规则场景携带。
8. 等阶发挥折扣：低阶持高阶只发挥部分。

### 4.5 优先级

试炼强制规则 ＞ 关卡特殊规则 ＞ S 级技能/死契 ＞ 常规装备技能 ＞ 生态惯例。

S 级"为打破规则而生"只指打破常规限制，不敌关卡强制规则。

### 4.6 避免点

1. 只写倍率不写机制。
2. 只给 CD 不给持续与消耗。
3. 把"无等阶要求"当零门槛。
4. 脑域占用随手填。
5. S 级写成万能破规则。
6. 死契只做背景板。
7. 治疗无上限。

## 5. 道具卡设计模板

### 5.1 分类

一级分"主动道具（可战斗/可释放）"与"辅助道具（耐久值、修理箱、医疗包、食物盒等）"，每次试炼只能携带其中一类。

### 5.2 必填字段

| 字段 | 规范 |
|---|---|
| 名称/等级 | 2–4 字可辨；F–S，辅助类可"无等阶" |
| 二级类型 | 攻击/防御/辅助/功能/资源/历练/杀戮/契约/具象/陷阱/源髓/傀儡/属性点 |
| 使用次数 | 一次性／2 次／4 次／5 次，注明是否可补充 |
| 单次效果 | 数值＋对象＋时长；治疗量对齐同阶修理箱 |
| 目标数 | 自身/单体/群体/宠物；群体必须写上限 |
| 冷却 | 现实 5 分钟全局 CD；试炼内用张数与单卡 CD |
| 使用条件 | 需近身/需命中/需死亡 3 天内/限年龄/限环境 |
| 道具槽 | 1 卡 1 槽，不可叠加 |
| 试炼携带 | 常规 1 张、死战 1 张、A 级争夺 4 张（按赛事分表） |
| 一次性标记 | 一次性/可补充/可叠加存放 |
| 获取/市价 | 试炼奖励/市场/公会/兑换；低阶万级、中阶百万级、高阶千万级 |

### 5.3 硬规则

1. 攻防功能类道具卡只能用 ≤自身等级；只有辅助类允许"无等阶"。
2. 现实世界任意两张卡之间至少 5 分钟全局冷却，不分种类；试炼内改按携带张数限流。
3. 持有者死亡，道具槽内卡随主人一并消失。
4. 一次性类型（杀戮/资源/特殊笔画）不可补充；杀戮类中途不可退出。
5. 同一携带者的两张防御卡不能同时释放，须战前调配。
6. 傀儡卡仅试炼内可用，回归即自动放弃。

### 5.4 避免点

万能卡池、同名跨档混用、攻防卡无等阶、试炼携带与槽位混算、一次性卡写成无限次。

## 6. 副本设计模板

### 6.1 副本五要素

每个副本必须先答完这五条，再写剧情：

1. 颜色：试炼卡颜色决定难度与属性上限。
2. 人数：单人 / 小队 / 大团，决定规模与卡色。
3. 匹配：个人按颜色分池；团队按年龄段 + 颜色。
4. 胜负：通关条件与失败条件必须明确。
5. 奖励：3–4 项，属性点 + 试炼卡 + 装备/技能/材料 + 道具卡，按颜色封顶。

### 6.2 十二种副本模板

| 模板 | 规模/卡色 | 核心玩法 | 胜负条件 | 奖励钩子 | 适配颜色 | 设计注意 |
|---|---|---|---|---|---|---|
| 个人试炼 | 单人／白–黑 | 生存＋击杀＋采集多目标 | 达标或前 N 名 | 属性＋试炼卡＋1 装备/技能＋1 道具卡 | 白–黑 | 必须 3–4 项；试炼卡可能被挤掉 |
| 年龄段团队 | 3–5 人／白卡 | 同龄协作通关 | 前 N 队或目标达成 | 属性（白 4/人）＋掉落品质 | 白 | 带高龄/高阶即抬档，须赛前明示 |
| 小队副本 | ≤5 人／紫卡 | 探索、竞速、护送三选一 | 时限或目标达成 | 属性（紫 25/人）＋材料 | 紫 | 3 天窗口、当月完成 |
| 大团副本 | ≤20 人／金卡 | 多环淘汰、占点、充能、守城 | 通过全部环数 | 属性（金 50/人）＋环宝箱＋终局抽奖 | 金 | 禁止复用 15→10→5→3→1 |
| 资源争夺 | 500 人／5 天／50 岁以下 | 碎片、矿点、资源塔的夺取与持有 | 持有量排名 | 积分＋资源分红 | 红–金 | 结束即崩解；可掠夺；须报备 |
| 限时生存 | 单人/小队 | 存活＋资源管理＋互相猎杀 | 最后留存 5 人 | 属性为主，少物品 | 蓝–金 | 可放弃时点写死并全篇统一 |
| 防守推进 | 20–500 人／多队 | 守点充能、关隘求援、矩阵保卫 | 时间结束或毁坏阈值未达 | 积分＋图纸＋特殊奖励 | 紫–金 | 求援次数与回防队伍数写死 |
| 杀戮竞技 | 多队／2 天 | 无规则击杀，允许伏击与结盟 | 击杀最多的 5 支队伍 | 杀戮积分＋属性 | 红–金 | 中途不可退出；攻守计分倍率分开 |
| 阵营战/种族战 | 多族多国／分区战场 | 积分＋城池＋杀戮＋试炼物四线并行 | 总积分排名 | 兑换池＋种族清算 | 金–黑 | 末位抹除提前公示，并给翻盘机制 |
| 探索解谜 | 团队／不限 | 遗迹、机关、材料、地图碎片 | 抵达核心或解完全部节点 | 材料、图纸、配方 | 蓝–紫 | 可做"只发属性点与试炼卡"的轻奖励变体 |
| 隐藏/进阶关 | 原班人马／2/3 同意 | 难度跳档、信息不全、规则异常 | 通关即进阶 | 进阶资格、高阶技能 | 红–黑 | 隐藏关不结算奖励直接进阶；拒绝者付代价 |
| 虚拟空间训练 | 任意规模 | 模拟战、评分战、无真实资源消耗 | 胜负或评分 | 熟练度、积分、低阶技能 | 白–蓝 | 死亡必须真实，产出走实体通道 |

> 表中"适配颜色"是难度带。单人场直接用对应颜色试炼卡；团队场只能用白/紫/金，按难度带换算：白 = F–E，紫 = D–C，金 = B–A–S。

### 6.3 副本设计硬规则

1. 颜色定难度与奖励上限；试炼卡数量定次数；人数定规模。三者分开，不得混算。
2. 每场必须有明确的通关条件与失败条件，不能只有氛围。
3. 属性点按颜色上限结算，3–4 项；团队每人一份，无倍率。
4. 试炼卡入场消耗；成功高概率返还同色新卡；失败与退出不发属性点、不返还卡；返还占奖励项。
5. 死亡＝随身物品全失；非死亡型可退，判失败扣最高项 20 点。
6. 副本内规则优先级：试炼强制 ＞ 关卡特殊 ＞ S 技能/死契 ＞ 常规装备技能 ＞ 生态惯例。
7. 禁止复用原著的标志性数字与关卡名；大团环数、淘汰节奏必须另算。
8. 每个副本至少一个"非战斗解法"或"可放弃窗口"，避免纯数值卡关。
9. 首通无属性倍率；如需剧情奖励，只给情报、图纸、一次性道具，且限量。

### 6.5 避免点

1. 只有背景、没有通关条件。
2. 奖励超过颜色上限，或额外给倍率。
3. 团队场写成"人多奖励多"。
4. 试炼卡不消耗，导致次数失控。
5. 死亡无代价，紧张感归零。
6. 副本难度跟人物等阶走，导致高阶回低色场也能拿高奖励。
7. 复用"15→10→5→3→1"这类标志性组合。

## 7. 奖励与结算

| 颜色 | 完美通关上限 | 常规通关参考 |
|---|---|---|
| 白 | 4 | 2–3 |
| 黄 | 8 | 4–6 |
| 蓝 | 15 | 8–10 |
| 红 | 20 | 10–14 |
| 紫 | 25 | 13–18 |
| 金 | 50 | 25–35 |
| 黑 | 100 | 50–70 |

规则：

1. 完美通关：主线 + 支线全清、无死亡、限时内、无残程。
2. 常规通关取上限的 50%–70%；完成度更高的按完成度线性折算，完美通关取满上限，不额外加成。
3. 无首通加成、无团队倍率、无越档倍率、无任何其他乘区。
4. 每次结算 3–4 项：属性点 + 试炼卡（高概率返还同色）+ 装备/技能/材料 + 道具卡。
5. 探索/搜索型只发属性点与试炼卡；复活者只结算属性点。
6. 同色递减取消：重复通关同一颜色，每次仍按该色上限结算。
7. 剧情级一次性奖励（遗迹首开、关键道具、排行榜）不属于倍率，可另设，但必须限量、写明来源。

## 9. 设计禁区

1. 原著专名一律不用：荧澪、五大陆、十三国、星界联合会、穹霄帝阙、七族死战、宇眼要塞、牧寒川、穆家、墨瞳族等。
2. 主角不得继承：恒落体魄、迁移额外携带 7 件、唢呐、棺材板、断乾尺。
3. 标志性组合至少改两项：3 件装备 + 1 张卡、15→10→5→3→1、脑域 13–17%、七色试炼卡。
4. "星门"必须拆分：入口型与战场型各起一名。
5. 死亡不继承遗物；不写无死契的 S 级；不写"无等阶＝零门槛"。
6. 主角所有"多带一件/多进一次/多学一个"的能力，必须在开篇给出明确代价与次数上限，且不随章节扩张。
7. 不给主角"属性奖励恒落单项"的特权。
8. 不设"一叠道具卡"式卡池，开战前必须报数。
9. 不写"无死契的 S 级技能"。
10. 不写"死亡遗物继承"。

## 11. 附录：种族与势力原型

### 11.1 种族十原型

| 原型 | 核心天赋 | 克制关系 | 可替换名称方向 |
|---|---|---|---|
| 控制系 | 短控/区域封锁/减速 | 克刺客、召唤；被远程、净化克制 | 瞳、律、印、锁、缚 |
| 刺客系 | 隐身/爆发/背刺 | 克后排、治疗；被控制、范围伤害克制 | 影、刃、夜、刺、猎 |
| 召唤系 | 傀儡/兽群/分身 | 克单体；被群攻、控制克制 | 驭、巢、牧、傀、群 |
| 再生系 | 蜕壳/自愈/断肢重生 | 克消耗战；被禁疗、爆发克制 | 蜕、芽、潮、苔、蛹 |
| 空间系 | 位移/封锁/传送 | 克近战；被规则压制、标记克制 | 隙、折、界、迁、门 |
| 精神系 | 心识攻击/幻象/读心 | 克低心识；被高心识、锚定克制 | 梦、念、歌、镜、识 |
| 群体增益系 | 光环/指挥/协同 | 克散兵；被斩首、分割克制 | 旗、律、歌、群、阵 |

| 寄生系 | 潜入/夺舍/寄生 | 克组织与情报；被检测、净化克制 | 寄、蔓、种、壳、孢 |

写作三律：一族一机制；强族必有内部排名；种族强弱与经济位置挂钩。

# 《全民入侵，种族试炼开启》规则库总表

## 0. 使用说明与口径优先级

1. 本表是小说硬规则的唯一口径：凡写作、改写、扩纲涉及试炼、属性、装备、技能、道具卡、经济与死契，一律以本表编号条目为准；与分段报告原文表述不一致时，按本表"推荐口径"执行。
2. 优先级链（高→低）：**试炼系统强制规则 ＞ 关卡/赛事特殊规则 ＞ S级技能及死契 ＞ A/B级装备与技能主动能力 ＞ 常规装备/技能/道具卡 ＞ 经济与生态惯例**。[章215][章739][章1129]
3. 同级冲突的裁决顺序：系统面板/公告 ＞ 规则条文 ＞ 角色口述；后章明确数值 ＞ 前章数值；例外条款 ＞ 通则。角色谎言（如"断乾尺不是装备"）不进入规则层。[章923][章967]
4. 标注约定："约"=原文区间或换算；"存疑"=原文口径不全、不得写死；"例外：章N"=该条仅在该章/该类关卡成立。
5. 数值统一口径：属性点一律写"点"；冲击/承伤一律写"焦耳"；时间按原文单位；概率按原文百分比。原文未给的数值不补写。

## 1. 参赛与匹配

- R-001 年满18岁自动获得白色星钥；18岁前不可进入试炼，也不能使用试炼装备、技能、道具。[章2]
- R-002 20岁前不可参加高阶试炼，只可进入常规/低阶场。[章702]
- R-003 普通星钥只能进单人试炼，每月2次，月内任选时间。[章4]
- R-004 银色星钥团队≤5人、金色星钥团队≤20人；银/金每月二选一，只能进1次。[章4]
- R-005 团队试炼须在开启后3天窗口内进入，且当月完成，不可跨月筹备。[章10][章1139]
- R-006 星钥、死战道具卡须本人主动标识才生效，他人签名无效。[章474]
- R-007 每人最多标识1张银色或金色星钥，进入后方可标识新的；每月只能择其一进入一次。[章1139]
- R-008 星钥标识后，除持有者本人外全员姓名遮蔽，可匿名组队。[章1137]
- R-009 团队试炼按年龄段匹配，不按实力；带高龄或高阶队员会抬高档位、放大难度。[章110]
- R-010 个人试炼按等阶匹配；特殊类关卡改按年龄段匹配。[章273]
- R-011 年龄分层原则上只约束团队试炼，个人试炼极少限龄。[章356]
- R-012 年龄限制单向：只限制更高年龄段，低年龄段可助力、可跨段挑战。[章1116]
- R-013 异族寿命差异由规则自动校正，维持77个文明种族年龄段大致平衡。[章356]
- R-014 匹配划分两个区间，差距过大或跨区种族一般不相遇。[章462]
- R-015 轮次精英赛分25骨龄以下、35骨龄以下，一月一轮，随机单挑，不占个人试炼次数。[章80][章88]
- R-016 月度总配额3次：个人2次＋团队1次。[章1129]
- R-017 25岁种族赛报名须保留1次个人试炼次数，并消耗1张蓝色星钥。[章188]
- R-018 A级争夺须各国报备、消耗蓝色星钥，并自动扣除当月1次个人试炼。[章498]
- R-019 七族死战消耗1张蓝色星钥，不占个人试炼次数；青煌固定200名额，须1名30岁段前百带队。[章686][章678]
- R-020 七族死战另开放全球自愿报名，不限国家、职业、履历，眷族除外，须达参赛标准。[章678]
- R-021 资源空间完全开启：持续5天、50骨龄以下、限500人、结束后崩解。[章457]
- R-022 B级资源关卡：25岁以下限大陆前100名，30岁以下无限制。[章347]
- R-023 穹霄帝阙探索名额：40岁以内每族每年龄段仅1个，人族25/30/35/40各1人。[章1084]
- R-024 官方金色大团可强制无偿标识金色星钥作为参赛前置。[章506]
- R-025 团队指挥权必须唯一，不接受主次不明的两拨人。[章110]
- R-026 临时组队与星环类自由组队上限均为3人。[章528][章64]
- R-027 团队试炼空位可出售，约500万/席，但星钥须提前标识本人。[章622]
- R-028 金色大团可主动放弃；把对手逼退（对方放弃）计为击杀并照发奖励。[章1054]
- R-029 非死亡型试炼可自主脱离，脱离判失败、传送回母星，并扣最高项属性20点。[章1045]
- R-030 死契战对手实力必定高于己方；同阶也可匹配（D级对D级），仍可能遇S级技能持有者。[章191][章503]

## 2. 关卡、星钥与解锁

- R-034 红色关卡通关累计5/5解锁紫色星钥；未解锁时持紫钥亦不可开启。[章194]
- R-035 通关个人试炼通常返还同色星钥，但星钥属概率掉落，会被高价值奖励占位而挤掉。[章4][章52]
- R-036 属性点产出档：蓝5–8、红12–13、紫13–18、黑更高（原文未给具体值）。[章52][章107][章254]
- R-037 死亡率梯队：白1–2成、黄2–3成、蓝红显著升高、普通紫低、黑极高。[章200][章273][章943]
- R-038 蓝色通关后可触发红色进阶关，须2/3参与者同意；拒绝者奖励压至极低，连紫色星钥都不发。[章1][章653]
- R-039 隐藏关通关不结算奖励，直接开启紫色隐藏关；解锁度以1/5起记。[章1]
- R-040 紫色个人阶梯淘汰：30名25岁以下→第二层20通道留20人→第三层10通道留10人，未过者强制回归。[章273]
- R-041 常规个人试炼单关约300–330名各族参与者。[章1][章653]
- R-042 杀戮型关卡：无规则，2天期限内击杀试炼者最多的5支队伍通关。[章447]
- R-043 生存型关卡：无时限，12小时后可主动放弃，最后留存5人通关。[章854]
- R-044 争夺型计量：每2小时随机降5枚碎片、持续48小时、可掠夺、按持有数量排名。[章196]
- R-045 黑色试炼单向不可回头；遇试炼者或原生怪物必须战胜才能继续；败者强制踢出并伴重伤/陨命。[章981]
- R-046 黑色试炼设通关计数器（本例1/5），跨阶累计；A阶后累计5次开单属性S级门，四属性全S需20次。[章981]
- R-047 黑色试炼S级奖励概率：单人1%、邀1人3%、双人死战5%，其余为A级。[章1116]
- R-048 黑色试炼限时10分钟，失败30秒后传送回归。[章492]
- R-049 金色大团环界：20队争第五环15名额→10→5→3→1；每过一环全员+5基础属性。[章582]
- R-050 宝箱首次接触获临时所有权，须持有3分钟解锁，离手计时重置；被夺后不可再掠夺。[章583]
- R-051 星台分上/中/下三层，各队须各占一座充能，三层全满方可通过；星能不可掠夺，但已充能量可被破坏。[章590]
- R-052 灯塔充能：每3分钟+1%亮度（满分约5小时）；黑夜坠落星核每枚+3%。[章612]
- R-053 超级城池日积分：一/二号城1000/750/500；三号城1200/900/600；最高10名占据者分超等1、高等3、下等6。[章799]

- R-058 中级星门内压制攻方：敏捷、心识各削减一成。[章1161]
- R-059 关隘求援限10支队伍回防、倒计时200秒，每座关隘仅1次机会。[章1158]
- R-060 试炼星与现实时间流速约4:1（内4天≈外1天）；禁断星环固定12小时出关，与内部停留时长无关。[章162][章81]
- R-061 通关提示"达到通关要求"，可立即回归或30秒后自动回归；失败30秒后传送回归。[章466][章492]
- R-061a 试炼结束/失败弹出二选一：【回归进入原点】或【回归进入地点的方圆二十公里随机区域】；"原点"＝入场时所在位置，队友各自回各自原点，宠物回原位；未夺取到奖励者无法随机传送，强制回原点。[章3][章10][章33][章52][章194][章723][章1091]
  - 新书裁决：只保留第一款（回归原点），第二款随机区域及矿窟集体传送、城池/要塞撤退回归等一切特殊回归均删除。

- R-062 三神座：随机两队各出3人分战3座，三局两胜决定生道/死道；生道3队、死道1个通关名额。[章1073]
- R-063 试炼星节点崩坏按5%→10%→15%→25%→30%递进，崩坏50%开启各年龄段资格挑战。[章1084]
- R-064 穹霄帝阙唯一奖励为"黑色个人试炼通关次数+1"，该次数是S级入场券。[章1084]
- R-065 关卡内主动退出视作失败，无任何奖励；部分死斗3小时内不可放弃、不可退出。[章148][章667]

## 3. 属性成长与脑域承载力

- R-066 四维属性为力量、体魄、敏捷、心识；一切门槛按单项或四项总和判定。[章1]
- R-067 1/4规则：最低属性不得低于最高属性的1/4；不足时奖励点强制拆分补足到低项。[章1][章4]
- R-068 属性奖励按资质倾向分配，允许100%落单项；牧寒川为恒落体魄的特例。[章1]
- R-069 等阶门槛可锚定点：E≈单项300、D≈单项600；F≈单项80（由需求反推）；B=2400（单项/总和口径存疑）；C/A/S未定义。[章1][章2][章433]
- R-070 高阶试炼综合门槛：≥1800可入万相狱；30岁段≥2000；C级战力可豁免。[章723][章750]
- R-071 无等阶要求装备/技能以"属性点自配总和"为门槛：700/800/1300/2500，分配后永久锁定、不可更改。[章194][章231][章478][章790]
- R-072 随机属性点卡幅度按色阶：白1/黄2/蓝3/红4/紫5/黑6。[章128][章19][章249][章575][章620]
- R-073 随机属性点卡冷却按天赋取值：常见6/7/8天，最差22天；月度上限=30÷冷却（6天≈5张）。[章107][章337]
- R-074 随机属性点卡价格锚点：白100万、黄200–230万、蓝350–410万、红530–600万、紫670万、黑900–1100万。[章654][章244][章208][章690]
- R-075 指定属性点卡价格=同色随机卡×3（蓝约900万）；紫色指定卡约1500–2000万。[章11][章367][章979]
- R-076 指定紫卡固定+5；隐性档可+6；部分指定卡每名试炼者一生只能使用一次。[章367][章860]
- R-077 随机卡落点不可控、允许"赌错属性"，可交易可赠送；随机属性点卡不受试炼场地携带限制。[章11][章293]
- R-078 属性点卡月度总使用上限6张；与个人冷却叠加后实际以孰低为准。[章1134]
- R-079 大治疗消耗1点体魄，恢复约四成状态；小治疗只走冷却（12小时）。[章784][章241]
- R-080 隐性加成只加本体，不可作用于装备、技能佩戴；显性加成可叠装备与技能。[章581][章313]
- R-081 脑域承载力初始13%–17%（个体差约4个百分点），此后主要随心识等阶成长；药剂等外因不计入成长曲线。[章905]
- R-082 技能脑域占用基准：F 2%–3%、E约5%（功能型特例9%）、D约6%、C 8%–10%、S 15%–16%。[章2][章242][章278][章1160]
- R-083 每头傀儡约占2%–2.5%脑域；5%可带两头。[章242][章1160]
- R-084 装备可要求脑域承载力8%/10%/12%/13%/16%，为硬性装配门槛。[章231][章314][章478][章433]
- R-085 脑域可被永久削减3%作为高阶能力代价；亦可永久+1%（浑天兰）。[章829][章661]
- R-086 脑域不足即不可学习，即便空有技能槽；脑域是硬闸、槽位是软条件。[章32][章181]
- R-087 属性达600点为D阶门槛，突破D阶时攻击强度提升两成。[章685]
- R-088 沉眠基因针剂分阶段、不可逆；注射一阶后只能接二阶，两针之间休息2小时。一阶心识激活81%→心识+24、脑域+2%。[章242][章157]
- R-089 基因针剂价格：一阶力3000万/体2500万/敏·心2000万；二阶力8000万以上/体7500万/敏·心7000万。[章200][章350]
- R-090 精骴：黄色随机+20且属性加成减半；金色随机+40、附2%单项且无副作用、仅本人可用。[章677]
- R-091 烬果最高七彩，每名试炼者一生最多服3颗（不论品质）；三彩可指定属性+30；S级烬果永久+10体魄或力量，并附一天增益。[章832][章781]
- R-092 月翠芽：真果自选属性永久+2、综合战力+10%；伪果随机+1、战力+5%；假果战力-10%且不扣属性。[章1099]
- R-093 柑莓随机+5属性；韧木核+半年寿命且仅人族；光果综合实力+一成并附主动退出权。[章510]
- R-094 属性转换仅允许高属性→低属性，每次50点，转换后仍须满足1/4规则。[章129]
- R-095 跨年龄段只折算"高出等阶"的攻击力二成加成，其余差距不能折算。[章593]
- R-096 装备可反向补属性以凑门槛；脱下配点装备后属性可跌破门槛。[章330][章340]
- R-097 伴生物可提供永久属性与战斗增益，不可交易、只能自得，资源可累积体内不必每月取出。[章356][章1069]

## 10. 规则优先级与例外清单

1. **试炼强制规则最高**：入场年龄、携带上限、退出/失败惩罚、死亡结算均由试炼规则决定，S级技能亦不可豁免。[章215][章346]
2. **关卡特殊规则可覆写常规**：七族死战7件装备、无武器约束；A级争夺4张道具卡；死战卡1张；均以赛事规则覆盖常规3件+1卡。[章739][章527][章540]
3. **S级技能可破常规但不可破强制规则**：迁移可把携带上限从3件推到约10件，但仍在试炼规则框架内，且占标记位、暴露能力。[章3][章6][章1129]
4. **S级技能与死契绑定**：S级必挂死契，每3个月强制死战；死契战只能一人活，胜者得50点高转低权柄。[章3][章881]
5. **例外：迁移突破携带**——S级"迁移"额外携带7样，合计约11件（含1张道具卡）；此为唯一被默认的携带上限例外。[章3][章6]
6. **例外：七族死战解除装备约束**——7件装备、7件武器叠满；离开该赛事即恢复常规3件。[章739]
7. **例外：A级争夺4张道具卡**——高于常规1张，低于七族死战2张+宠物扩充；仅该赛事成立。[章527]
8. **例外：死战道具卡内1张**——即使现实已开多槽，进入死战卡空间仍只带1张。[章540]
9. **例外：现实8件**——8部位装备在现实可同时生效，但出门受国家法规3件限制；公职例外。[章869][章293]
10. **例外：无等阶要求装备**——不看等阶、低阶可穿，但仅隐藏试炼、超难关卡、每关第一名产出。[章195]
11. **例外：辅七星6小时强制回归**——普通高级城池可6小时内主动回归，辅七星该能力失效，须等满6小时自动回归。[章811][章821]
12. **例外：天虹瀑提前脱离**——默认生存型12小时后可放弃，天虹瀑第4小时即开放脱离。[章856]
13. **例外：穹霄帝阙**——40岁以内每族每年龄段仅1个名额；奖励为黑色通关次数+1，直接绑定S级突破路径。[章1084]
14. **例外：复活**——唯一稳定复活渠道为金色大团第1/2/3名=3/2/1个名额；未触发则真死。[章220][章1110]
15. **例外：死亡结算**——死亡者装备、技能、饰品、伴生物全部消失，任何"遗物继承"写法均违规。[章832]
16. **例外：规则小岛**——S级技能召不出傀儡；关卡规则可压制S级技能，优先级高于技能。[章346]
17. **例外：最终BOSS前冷却刷新**——进入最终BOSS节点前，所有技能与装备冷却重置；其他场景不自动刷新。[章617]
18. **例外：属性转换**——仅S级死契权柄可高转低，每次50点，且转换后仍须满足1/4最低项规则。[章129]

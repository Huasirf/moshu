# 技能设计细则

> 依据《全民入侵》第 1–1168 章正文，技能样本 360 段全量提取。
> 标注：**样本**＝原文有明确数字；**建议**＝按锚点推导；**存疑**＝原文自相矛盾。
> 本书技能定价的总纲是原文自述：「S 级技能，其实限制也很大，越变态的限制必然就会越多，这可能就是平衡」（第 107 章）。

---

## 一、技能分级与系别

### 1.1 七档分级

| 等阶 | 定位 | 已知脑域占用 | 已知获取渠道 | 章号 |
|---|---|---|---|---|
| F | 入门 | 2%～3% | 首通奖励、市场 | 2、65 |
| E | 常规主力 | 约 5%（功能型例外 9%） | 试炼奖励、市场 | 242、278 |
| D | 中阶 | 6% | 试炼奖励、拍卖 | 278、227 |
| C | 高阶 | 8%～10% | 种族赛、特殊奖励 | 1160 |
| B | 稀有 | 未记录 | 种族赛 | 440 |
| A | 顶级 | 门槛 13%（占用未记） | 种族赛、10000 积分兑换 | 435、433、478 |
| S | 规则级 | 15%～16% | 黑色关卡、特殊类、辅七星 | 1、433 |

两条容易写错的边界：

1. **技能等阶 ≠ 试炼者等阶**。升级 A 阶的硬条件是「通关 5 次紫色个人试炼 + 1 次黑色个人试炼」（第 1089 章），与技能本身标注的等级是两套体系。
2. **高功能技能有「溢价」**：E 级群体治疗占 9%，高于普通 D 级技能 6%（第 278 章）。这不是笔误，而是「一个技能干三件事」的定价，但必须在字段里注明溢价理由。

### 1.2 系别与掉落池

| 系别 | 特点 | 掉落/获取 | 章号 |
|---|---|---|---|
| 战斗系 | 攻击为主，S 级必须进黑色关卡或特殊类试炼，难度「堪比登天」 | 黑色关卡、特殊类 | 2 |
| 辅助系 | 辨识、团队助益；S 级有微小几率出现在进阶类紫色关卡 | 紫色进阶关卡 | 2、32、133 |
| 控制系 | 单体/小面积，脑域占用低；战场优先击杀目标 | 各类试炼 | 169、173 |
| 空间系 | 「太过逆天」，可凭空多出装备，暴露风险极高 | 少见，需隐藏 | 27、1029 |
| 治疗系 | 群体治疗 E 级即可学但占用高，且「有治疗上限」 | 试炼奖励 | 278 |
| 召唤系 | 傀儡卡占 2% 脑域；奴役体只能在试炼星用，回归即放弃 | 傀儡卡 | 1160、82 |
| 被动系 | 可为无消耗永久效果，但冷却可达年级 | 极稀有 | 194 |
| 保命类 | C 级特殊保命技占 8%，是 C 阶玩家核心资产 | 特殊奖励 | 1160 |
| 特殊类 | 用「属性点自配总和」替代等阶门槛 | 各档兑换 | 231、314、478、790 |

掉落池决定叙事：**战斗系 S 级只能从黑色关卡出**，所以「拿到 S 级攻击技」本身就是一场生死战的凭证；辅助系 S 级能从紫色进阶关卡出，才解释得通「非战斗型强者也有 S 级」（第 2 章）。

携带限制按类目算：攻击类装备与技能都有携带上限，特殊饰品唯一（第 1008 章）。C 阶之后奖励结构改变，以消耗品为主（第 861 章）——**高阶技能不靠刷本，靠赛事与兑换**。

## 二、学习条件与脑域承载力

### 2.1 四重门槛，缺一不可

学习 = 等阶/属性门槛 + 脑域承载力 + 技能槽 +（部分）前置。

判定顺序的关键证据：

- 「他都学四个技能了，你的脑域承载力足够？」（第 48 章）
- 「技能满了，没有足够的脑域承载力」（第 308 章）
- 「脑域承载力只剩 1%，真开启三个技能槽也不允许他学」（第 32 章）→ **脑域是硬闸，槽位是软条件**
- 「脑域承载力剩余 0 的我，什么都学不了」（第 181 章）

### 2.2 属性门槛实例

| 技能 | 属性要求 | 脑域 | 章号 |
|---|---|---|---|
| 蛛网禁锢（F，控制） | 心识 100、敏捷 80 | 3% | 2 |
| 修理（F/E，辅助） | 只需 F 级力量与敏捷属性点要求 | 未记 | 12 |
| 迁移（S，辅助） | 无属性点要求、无等阶要求 | 15% | 1 |
| 白骨生莲（C，特殊） | 属性点自配，总和 700 | 10% | 231、307 |
| 未标等级特殊技能 | 总和 800 | 12% | 314 |
| 阴阳冢（A，攻击） | 属性自配，总和 1300 | 13% | 478 |
| 九宇（高阶特殊） | 属性自配，总和 2500 | 16% | 790 |
| 九星高照·技能类（C 兑换物） | 无属性点要求 | 0% | 745 |

**「无等阶要求」名不副实**：它免的是「等阶」，不是「属性」——实际门槛是 700/800/1300/2500 总属性（第 231、314、478、790 章）。写作时应改称「总属性门槛型」，否则读者会误以为低阶白拿。

### 2.3 脑域：真正的定价单位

| 对象 | 占用 | 原文 | 章号 |
|---|---|---|---|
| F 级 | 2%～3% | 「最低阶的 F 级技能也需要 2%」 | 2 |
| E 级普通 | 约 5% | 「有了 5% 的脑域承载力，刚好可以学上一个 E 级技能」 | 242 |
| E 级群体治疗 | 9% | 「普通的 D 级技能只占 6%……这个群体治疗足足高出一半」 | 278 |
| D 级普通 | 6% | 同上 | 278 |
| C 级攻击（影牙） | 10% | 「攻击技能：影牙（C）耗去 10%」 | 1160 |
| C 级特殊保命 | 8% | 「C 级特殊类的保命技能耗去 8%」 | 1160 |
| 傀儡 | 2% | 「又花去 2%」 | 1160 |
| S 级迁移 | 15% | 「脑域承载力需求：15%」 | 1 |
| S+F 合计面板 | 18% | 「【技能：迁移（S级），初级洗礼（F），2/2，脑域占据 18%】」 | 497 |

初始值：13%，且只随心识等阶成长（第 905 章）；同章另一角色为 17%，说明**初始值允许 4 个百分点的人物差异**。16% 被描述为高阶门槛，「最少需要提升到 B 级才可能达到，B 级需要 2400 点心识」（第 433 章）。

脑域是「永久吃掉技能位」的代价，比冷却更狠：S 级占 15%～16%，学完只剩 1%～2%，几乎再学不了任何东西（第 1164、497 章）。还有更极端的永久代价——「永久削减 3% 的脑域承载力」（第 829 章）。

### 2.4 技能槽：可交易的稀缺品

- E 阶基础 2 槽（第 16 章），面板写法「2/2」（第 497 章）。
- 槽位靠奖励道具增加：「初级技能槽 +1」「中级技能槽 +1」（第 32、34、198、201 章）。
- 槽位可流通：一个初级技能槽卖了 180 万（第 38 章）。
- 槽位是软条件：即便 3 槽，脑域只剩 1% 也学不了（第 32 章）。

### 2.5 抹除、封印与进阶

| 道具 | 功能 | 价格/限制 | 章号 |
|---|---|---|---|
| 技能抹除卡（F） | 抹除已学 F 级技能，腾位 | 约 50 万 | 153 |
| 技能封印卡（E） | 封印 E 级技能 15 分钟 | 时机难把握 | 156 |
| 技能消除卡 | 进阶型技能不需要 | — | 354 |
| 高阶抹除卡 | 稀薄到「本次七族死战内几乎找不到」 | — | 790 |

进阶型技能可免消除卡：E/D/C 一路进阶至 B，「只要搞到更高阶的，直接就可进阶」（第 354 章）。这为「同一条技能线写四张卡」提供了合法结构。

## 三、技能字段模板

```
skill_id / name            名称
tier                        F|E|D|C|B|A|S|无等阶要求
school                      战斗|辅助|控制|治疗|空间|召唤|被动|保命|特殊
learn_req:
  tier_req                  学习等阶（可空=无等阶要求；与 skill tier 分开）
  attr_req                  单项门槛，或「属性自配总和 N 点」
  brain_req                 脑域占用 %
  slot_req                  技能槽（默认 1）
  prerequisite              前置（如修理等级 ≥ 装备等级）
effect:
  base                      数值/倍率/百分比
  scaling                   随等阶、属性、环境放大（逆风、阴暗）
  duration                  持续（秒/分/小时/天）
  range                     距离/半径
  target                    单体|小面积|全体|自身
  tags                      位移、控制、反弹、免伤、治疗、标记
cost:
  brain                     永久占用 %
  hp                        体魄点数
  attr_points               属性点数
  mind                      心识点数
  state_pct                 当前状态 %
  uses                      一月 3 次 / 一天 1 次 / 蓄 7~9 次
cooldown                    秒→分→时→天→年（必须给确定值）
side_effect                死契、治疗上限、非必中、仅特定环境、失败销毁、反噬
growth                      可进阶 E→D→C→B（免消除卡）/ 固定
panel_text                  【技能：X（S级），Y（F），2/2，脑域占据 18%】
source                      关卡 / 种族赛 / 积分兑换 / 市场 / 掠夺
```

面板标准写法直接取原文（第 497 章）：`【技能：迁移（S级），初级洗礼（F），2/2，脑域占据18%】`。

**必须拆开的两组字段**：`tier`（技能等级）与 `tier_req`（学习等阶）——原文两者经常不等（第 242、689 章）；`attr_req`（单项）与 `attr_total_req`（总和）——两套量表不可混算（第 231、433 章）。

### 4.1 消耗的五种类型

1. **脑域承载力**（主流，永久占用）（第 1160 章）。
2. **体魄**：每次 1 点（第 212、241、305 章）。
3. **属性点**：B 级以上「需消耗自身任意 10 点属性点」（第 209 章）。
4. **心识**：「融合需消耗 1 点心识」（第 962 章）。
5. **当前状态百分比**：「消耗当前 10% 状态，瞬间爆发 300% 速度」（第 689 章）。

### 4.2 冷却档位（可直接照抄的档）

| 档 | 代表数值 | 用途 | 章号 |
|---|---|---|---|
| 秒档 | 10 秒、30 秒 | F 级短控 | 169 |
| 分档 | 90 秒、2 分钟 | E 级控制 | 169 |
| 团辅档 | 10～15 分钟，持续 90～120 秒 | 群体增益 | 133、134 |
| 爆发挥 | 15～24 小时，持续 30 秒～5 分钟 | 单次强化 | 140、212、1120 |
| 战术档 | 9～18 小时，持续 0.8 秒～30 分钟 | 保命、反弹、分身 | 619、772、1125、784 |
| 战略档 | 48 小时～3 天 | 空间封锁、九宇分身 | 790、916 |
| 年级 | 5 年 | 被动重生（等同一次性） | 194 |
| 次数型 | 一月 3 次 / 一天 1 次 / 蓄 7～9 次 | 替代 CD | 857、406、728、1153 |

冷却即剧情：季焱「距离冷却时间还差 30 分钟，就差这 30 分钟，导致他无法脱身」（第 423 章）；另一人也「因为保命技能没过冷却时间，一样的死法」（第 427 章）。**保命技 CD 就是死亡开关**，必须能被角色当场算出来。

存在整体刷新机制：「所有技能、所有装备的冷却都将重新刷新」（第 617 章）——写跨界/换阶段副本时可用，但一场只能用一次。

## 五、S 级技能设计法则

### 5.1 强效果 + 死契/永久代价，必须成对

原文：S 级技能「有着附加死契」，每三个月必须参加一次死战（第 3、209 章）；死契是试炼强制规则，「就是拥有 S 级技能的牧寒川也无法打破」（第 215 章）。**本书不存在无死契的 S 级技能**。

| S 级样本 | 强效果 | 代价 |
|---|---|---|
| 迁移（第 1、3 章） | 标记并迁移物品/活体，可多带约七样，绕过三件装备上限 | 脑域 15%；每三个月一场死战 |
| 焚劫（第 790 章） | 斩破千米巨门的最强一击 | 脑域不足学不了；仅一次体验，失败则技能彻底消失 |
| 守护核（第 194、216 章） | 躯壳重生 | 5 年冷却，等同一次性 |
| 断乾尺·空间隔断（第 857、916 章） | 抗空间封锁 + 破空远距定向传送 | 一月 3 次 |

### 5.2 S 级限制清单（至少勾两条）

1. **脑域 15%～16%**：永久吃掉 3 个技能位（第 1、790、1164 章）。
2. **死契排期**：季度强制死战，且提前一个月提示（第 96、503 章）。
3. **次数上限**：一月 3 次 / 一生 1 次 / 5 年冷却（第 857、194 章）。
4. **非必中与落空反噬**：「18 小时冷却太长，且不是必中，万一打空，对方没事，我自己就先吐血」（第 435 章）。
5. **环境限定**：仅阴暗环境、仅极深地带、仅夜间（第 92、319、969 章）。
6. **失败销毁**：试用失败「这张 S 级技能将彻底消失」（第 790 章）。
7. **规则边界**：S 级技能默认不能跨规则场景携带，需特殊技能（迁移）才能带入（第 1129 章）。
8. **等阶发挥折扣**：低阶持高阶只能发挥部分，「D 阶用 A 级不过只能发挥四分」（第 608 章）。

### 5.3 优先级定序（必须写进设定）

试炼规则 > S 级技能 > 常规技能。依据：「证明 S 级技能是小于试炼规则的」（第 346 章）与「就是拥有 S 级技能也无法打破」（第 215 章）；而「S 技能本身就为打破规则而存在」（第 548 章）只能理解为「打破常规技能的限制」，不能打破试炼规则本身。若不定序，S 级会写成万能许愿机。

## 六、设计要点

1. **用脑域定价，不用倍率定价**：强技能吃掉一个永久技能位，比长 CD 更让玩家肉疼（第 1164、497 章）。
2. **每个技能都要能「算」**：射程、目标数、持续、CD 四项齐全，团战才能调度（第 330 章）。
3. **短控给低 CD、低占用**：F 级 10～30 秒、占 2%～3%，才有人愿意带（第 169、2 章）。
4. **团辅的 CD 是持续的 5～10 倍**：CD 10～15 分钟、持续 90～120 秒，节奏刚好一场团战一次（第 133、134 章）。
5. **爆发技给 30 秒～2 分钟窗口**：窗口内必须决战，窗口外必须挨打（第 140、759、406 章）。
6. **战术技统一放在 9～18 小时**：保命、反弹、分身都落在这个带，正好「一场一次」（第 619、772、1125 章）。
7. **S 级写成「资源型」而非「数值型」**：蓄 7 次、蓄 9 次、一月 3 次，让玩家管理资源（第 728、1153、857 章）。
8. **保命技要能被绕开**：不是无敌，而是「有 CD 的第二条命」，且对手可以算时间（第 423、427 章）。
9. **治疗必须带上限**：群体治疗「有着治疗上限」，单体大治疗则耗体魄（第 278、305 章）。
10. **给配角发「无消耗小技能」**：无消耗无冷却但只对单体有效，用来制造「他也有底牌」的意外（第 440 章）。
11. **功能压制优于掉血**：禁疗、压制精神类、规则性物理抑制，是高阶反制的主要手段（第 943、765 章）。
12. **技能要有「用不出来」的场景**：仅阴暗环境、非必中、需时机，错误场景直接失效（第 92 章）。
13. **进阶线要一次规划四张卡**：E/D/C/B 同名进阶，免消除卡，读者能预期成长（第 354 章）。
14. **修理类技能等阶必须 ≥ 目标装备等阶**：F 修 F、E 修 E 及以下（第 12 章）。
15. **掠夺是技能流通的一环**：死亡三天内、一生被抽 10 次、卡有档位，S 级必须 A 卡（第 838、684 章）。
16. **面板写法统一**：`【技能：X（S级），Y（F），2/2，脑域占据18%】`，一眼能读出槽位与占用（第 497 章）。

## 七、必须避免的坑

1. **错误写法**：只写倍率不写机制（「攻击 +20%」「提升三成」）→ **后果**：缺射程、目标数、可否打断，实战无法判定输赢 → **正确做法**：倍率后面强制跟「目标 / 范围 / 持续 / 可否打断」四项（第 140、134 章）。
2. **错误写法**：只给 CD 不给持续与消耗 → **后果**：配置库出现空字段，后期只能临时补设定 → **正确做法**：`duration`、`cost`、`cooldown` 三者任一为空即视为未完成（第 172、227、1160 章）。
3. **错误写法**：把「无等阶要求」当零门槛 → **后果**：读者以为低阶白拿 S 级，实际门槛是 700/800/1300/2500 总属性 → **正确做法**：改称「总属性门槛型」并写明点数（第 231、314、478、790 章）。
4. **错误写法**：脑域占用随手填（E 级群体治疗 9% > D 级 6%）→ **后果**：破坏「等阶越高占用越高」的直觉，读者算不出性价比 → **正确做法**：要么给溢价字段并说明「一技多用」，要么压回 5%（第 278 章）。
5. **错误写法**：把 S 级写成万能破规则 → **后果**：与「S 级小于试炼规则」直接冲突，所有绝境都能解 → **正确做法**：先定序「试炼规则 > S 级 > 常规」，再写能力边界（第 346、215 章）。
6. **错误写法**：死契只做背景板 → **后果**：S 级持有者长期不参赛，副作用形同虚设 → **正确做法**：给死契排期表，提前一月提示，且不可豁免（第 96、215 章）。
7. **错误写法**：把 5 年 CD 当常规冷却 → **后果**：CD 曲线被一次性复活拉爆，后续数值全乱 → **正确做法**：年级冷却单列「一次性复活/重生」类别（第 194 章）。
8. **错误写法**：技能槽奖励无限通胀 → **后果**：槽位不再稀缺，脑域模型失效 → **正确做法**：设总槽上限（原文缺失，需自定）（第 38、32 章）。
9. **错误写法**：技能等阶与试炼者等阶混写 → **后果**：「D 级技能要 D 阶」与「E 阶能学 D 级技能」并存，读者无所适从 → **正确做法**：拆成 `tier` 与 `tier_req` 两字段逐条录入（第 242、689 章）。
10. **错误写法**：掠夺概率不写期望值 → **后果**：C 卡最低 C，而目标只有 S 与 F，出现无合法抽取对象的规则黑洞 → **正确做法**：补「低于卡档自动降级/抽空返还」规则（第 684、838 章）。
11. **错误写法**：治疗无上限或被禁疗时无解 → **后果**：治疗系变成永动机，或整条线被一刀废掉 → **正确做法**：群体治疗写上限，单体大治疗写体魄消耗，并允许「禁疗」作为反制（第 278、305、943 章）。
12. **错误写法**：试用型技能不写失败惩罚 → **后果**：白嫖一次 S 级，稀有度归零 → **正确做法**：写明「体验态不占脑域、限一次、失败则技能销毁」（第 790 章）。

## 九、技能自检清单

写一个新技能前，逐项打勾：

- [ ] `tier` 与 `tier_req` 分开填；不存在「D 级技能必须 D 阶」的默认绑定（第 242、689 章）
- [ ] 属性门槛写成可计算数字，或写明「总属性 N 点」（第 231、478 章）
- [ ] `brain_req` 落在档位内：F 2～3%、E 5%、D 6%、C 8～10%、S 15～16%（第 2、242、278、1160、1 章）
- [ ] 若占用高于同阶均值，写明功能溢价理由（第 278 章）
- [ ] 技能槽消耗已标，且与面板 `x/x` 一致（第 497 章）
- [ ] 射程、目标数、持续时间、可否打断四项齐全（第 140 章教训）
- [ ] CD 是确定值，不写「较长」「较短」（第 330 章）
- [ ] 持续 ≤ CD 的 1/5；若超过，按被动定价（第 133、1120 章）
- [ ] 消耗类型落在五类之内（脑域/体魄/属性点/心识/当前状态）（第 1160、241、209、962、689 章）
- [ ] 若不是必中，写明落空后果（第 435 章）
- [ ] 若限环境，写明 `env_req`（第 92 章）
- [ ] 若为一次性/试用，写明失败销毁与次数（第 790 章）
- [ ] 若无消耗无冷却，必须限定目标类型或数量（第 440 章）
- [ ] 若为 S 级：死契 + 至少两条限制，且守「试炼规则 > S 级」优先级（第 3、346 章）
- [ ] 若为进阶型：写清 E→D→C→B 路径，并注明免消除卡（第 354 章）
- [ ] 若治疗系：群体写上上限，单体写上体魄消耗（第 278、305 章）
- [ ] 获取渠道符合系别掉落池（战斗系 S 只出黑色/特殊类）（第 2 章）
- [ ] 掠夺/交易规则已注明：习得即绑定，脱手需抹除卡（第 153、241 章）

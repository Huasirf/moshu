# 入场落点、试炼星周边与回归地点规则

> 依据：`01-规则库总表.md`、`02-逐章规则索引.md`、`05-世界观总结.md`、`07-配置文本/rulebook.txt`。
> 标注：**样本**＝原文有明文；**推断**＝由多条样本拼接；**新书**＝新书基线口径。

---

## 一、位置链总览

一次试炼要走完五个位置节点：

```
现实出发地 → 入场通道 → 试炼星落点（原点）→ 场内传送节点 → 回归现实
```

原著对中间三个节点写得很细，对"现实出发地"和"回归现实落在哪"几乎没写。这正是新书可以补的地方。

## 二、入场：从现实到试炼星

### 2.1 两种入场方式（样本）

| 方式 | 动作 | 适用 | 章号 |
|---|---|---|---|
| 随地处捏碎 | 原地捏碎星钥，就地传送 | 个人试炼、死战卡 | 546、1024 |
| 固定入口进入 | 到关卡入口，查验后放行 | 团队试炼、大型赛事 | 280、522 |

原著两者并存：个人场多为随地处捏碎，团队与赛事走固定入口。新书 v4.3 已统一为"试炼厅 → 通用核验口 → 单人封闭投候室 → 投放阵列"，不再随地处捏碎。

### 2.2 入场查验（样本）

- 关卡入口按"三件装备 + 槽内卡"逐项查验（第 280 章）。
- 入场有倒计时，样本为 60 秒（第 522 章）。
- 部分关卡通道需"识别圈 + 30 秒开启"（第 277 章）。
- 团队试炼可由雇主统一发卡，跳过战前布置（第 164 章）。

### 2.3 落点分配（样本）

| 规则 | 内容 | 章号 |
|---|---|---|
| 系统分配 | 落点由系统给出，玩家不选 | 1024 |
| 限时选点 | 资源塔争夺可在 30 秒内选定落点 | 403 |
| 集体传送 | 高级矿窟最多 5 人集体传送争夺 | 476 |
| 强制拆散 | 金色大团 1000 人入场后随机打散百区，同队不同区 | 213 |
| 年龄分层 | 试炼星区域按年龄段分层准入，低龄只能进浅层 | 152 |
| 召唤延后 | 宠物、傀儡可进场后再召唤 | 96 |

**关键结论**：入场落点不是"队伍集合点"，而是"系统投放点"。同队被打散是常态，集合本身就是一个战术动作。

## 三、试炼星周边：落点周围有什么

### 3.1 区域层级（样本）

试炼星不是一个平面副本，而是有纵向深度与横向分区：

| 层级 | 内容 | 章号 |
|---|---|---|
| 浅层 | 低年龄段可进，奖励低 | 152 |
| 深层 | 高年龄段、高阶装备才能深入 | 152 |
| 节点 | 一号节点崩坏会破开禁域 | 1084 |
| 禁域 | 穹霄帝阙，40 岁以内每年龄段 1 个名额 | 1084 |
| 隙潮 | 随机爆发的高密度战场 | 712 |
| 深渊区 | 高危种族活动区 | 433 |

### 3.2 落点周边的固定设施（样本）

| 设施 | 功能 | 规则 | 章号 |
|---|---|---|---|
| 资源塔 | 采分、夺塔 | 每日正午刷新 3000 座，可随机传送抢位 | 375 |
| 城池 | 据点、传送、积分 | 每日可绑一城，5 分钟抵达，6 小时内可主动回归 | 799 |
| 中级城池 | 撤退传送点 | 3 小时后才能回归 | 822 |
| 要塞 | 守方总据点 | 可捏碎全队传送回要塞 | 1146 |
| 关隘 | 天险、求援点 | 每座仅 1 次求援机会，限 10 支队伍回防 | 1158、1165 |
| 星门 | 攻防目标 | 2 高级 + 20 中级 + 500 低级 | 1145 |
| 补给点 | 回血回粮 | 可能已成废墟 | 1055 |
| 矿窟 | 采分点 | 离开即回原点 | 476 |
| 安全区 | 夺塔期的免战区 | 夺塔结算后自动消失 | 379 |

**写作用法**：落点周围不要写成空地。角色一落地，先看到的是塔、城、关隘、补给点——这些设施本身就是目标与威胁，读者立刻知道"往哪走"。

### 3.3 "原点"机制（样本，最容易被漏）

原点 = 入场时的落点，是场内锚点。

- 离开特定区域（矿窟）即自动回归原点（第 476 章）。
- 关卡失败传送回原点，不是回现实（第 815 章）。
- 原点不是安全区，只是一个坐标。

这条规则的价值在于：**失败不等于出局**，很多关卡失败只是"重来一次"，代价是时间与暴露。

### 3.4 特殊战场的地理（样本）

| 战场 | 特征 | 章号 |
|---|---|---|
| 禁断星环 | 固定 12 小时出关，与停留时长无关 | 81 |
| 虚拟空间 | 死在其中即真实死亡 | 71 |
| 穹霄帝阙 | 节点崩坏后破开的禁域 | 1084 |
| 七族死战分区 | 白主星 / 双主星 / 辅三星 / 辅五星 / 辅七星 | 699、739、818 |
| 希罗络城 | 星环内的城池试炼 | 655 |
| 喙苍岭 | 人族金色试炼战场，海拔 6000 米以上 | 1139 |
| 宇眼要塞 → 时眼关隘 → 亡眼关隘 | 守方纵深防线 | 1145、1154、1162 |

## 四、场内传送

### 4.1 传送类型（样本）

| 类型 | 触发 | 落点 | 章号 |
|---|---|---|---|
| 关卡推进 | 集齐信物/达成条件 | 下一层 | 168、301 |
| 失败回原点 | 关卡失败 | 入场原点 | 815 |
| 随机抢点 | 资源塔刷新 | 30 秒内自选 | 403、375 |
| 城池传送 | 绑定城池 | 城池内，5 分钟抵达 | 799 |
| 全队回要塞 | 确认回援 | 要塞 | 1146 |
| 集体争夺 | 高级资源点 | 多人同点 | 476 |

### 4.2 传送限制（样本）

> 新书口径：以下传送只作为**场内移动**保留；凡是“传送回现实”的特殊回归（城池撤退、要塞回传、关隘回传）一律删除，回归只认预设安全点或十公里环带。

- 超级城池每日最多 50 次传送（第 799 章）。
- 中级城池作为撤退点，需等 3 小时才能回归（第 822 章）。
- 辅七星回归倒计时可被外部精确计算（第 822 章）。
- 关卡封闭期间传送失效：光幕封闭、辅七星封印后，回归与传送全部断掉（第 770、823 章）。
- 进入不可脱离区域后，传送点不再响应（第 991 章）。

### 4.3 传送的战术意义

- 传送次数是资源，不是无限技能。
- 城池是"落脚点 + 撤退点 + 积分点"三合一，所以争夺城池等于争夺机动权。
- 原点机制让"失败"变成可承受的成本，关卡可以设计成多轮尝试。

## 五、回归现实

### 5.1 回归时点（样本）

| 类型 | 时点 | 章号 |
|---|---|---|
| 通关 | 提示后立即，或 30 秒倒计时自动 | R-061、1124 |
| 失败 | 30 秒后 | 492 |
| 银团失败 | 即刻 | 868 |
| 死战结束 | 30 秒后 | 549 |
| 主动放弃 | 立即 | R-029 |
| 强制回归 | 满时自动（辅七星 6 小时、禁断星环 12 小时） | R-056、R-060 |

### 5.2 回归地点：预设安全点或十公里环带（新书口径）

原著给的是二选一面板：

> 【试炼结束】
> 【一：回归进入原点】
> 【二：回归进入地点的方圆二十公里随机区域】

出处：第 3、52、194、1091 章；第 92、264 章是角色实际选第二项的过程。

新书保留第一项，把它改写为“预设安全点”；把第二项从二十公里收窄为十公里环带。

| 原著形式 | 新书处理 |
|---|---|
| 回归进入原点 | 改为“预设安全点”：入场前登记的现实坐标 |
| 方圆二十公里随机区域 | 改为“十公里环带”：以入场地点为圆心，半径十公里内随机 |
| 矿窟类集体传送去资源区 | 不采用 |
| 城池 / 要塞 / 关隘传送回传 | 不作为回归落点；场内移动另行处理 |
| 隙潮、月牙魂等强制传送回原点 | 合并进“场内回原点”，不单列 |

新书的回归规则一句话：**试炼结束、失败或主动退出，落点是预设安全点，或入场地点十公里环带内的随机点；默认走环带。**

### 5.2.1 预设安全点

- 入场前在核验口登记一个现实坐标：住所、仓库或安全屋，回归直接落在该点。
- 登记只存坐标与登记时间，不存货源、不存交易记录。
- 每人每季度可改一次，改后下一次入场生效。
- 安全点不是系统保护：落地同样只有 30 秒白圈。
- 主角不登记安全点。仓库是租的，登记等于把地址交给系统留档；他宁可走环带，再换装绕回。

### 5.2.2 十公里环带

- 以本次入场地点（试炼厅投放口）为圆心，半径十公里的环带内随机落点。
- 落点不固定，外人无法用入场地点反推具体出口，这是防蹲守的主手段。
- 环带不是安全区：落点可能是街口、废弃工地、别人家后院，周围可能有蹲守者、拾荒者、跟踪者。
- 十公里写死，不逐场变化。

### 5.2.3 倒计时

原著三处不一致：约 50 秒（第 52 章）、60 秒（第 194 章）、30 秒（第 1091 章）。

新书统一为 **30 秒**，写进关卡卡，不逐场变化。

### 5.2.4 谁回哪里

- 每人各回各的落点，不回队长的落点（第 33、92、460 章）。
- 宠物回自己原来的位置（第 460 章）。
- 失败、主动放弃、未达标，同样回归，落点规则不变（第 723、750、791 章）。
- 首试例外：返程由系统回收到投放阵列，不适用安全点与环带。
- 私人远征（返界锚）不走公共规则，固定回两个私路坐标。

### 5.2.5 落点蹲守与 30 秒白圈

- 安全点坐标可能被熟人摸到；环带落点也可能撞上蹲守者（第 96 章）。
- 落地自动生成白圈防护，**只存在 30 秒**（第 476 章）。
- 30 秒之后，安危自负。

**写作模板**：CH103 灰隼查货，主角靠环带落点＋换装甩掉跟踪；安全点反而不能用，一用就暴露仓库。

### 5.2.6 新书映射

| 项 | 新书 |
|---|---|
| 回归方式 | 二选一：预设安全点 / 十公里环带 |
| 默认 | 十公里环带 |
| 安全点登记 | 只存坐标，不存货源；每季度可改一次 |
| 随机区域 | 二十公里改十公里 |
| 特殊传送回归 | 全部删除 |
| 倒计时 | 30 秒 |
| 防护圈 | 保留 30 秒 |
| 首试 | 系统回收投放阵列 |
| 私路 | 固定两个坐标 |

### 5.3 回归时的状态（样本）

| 项目 | 规则 | 章号 |
|---|---|---|
| 伤势 | 保留。重伤者回归即重伤，需自行医治 | 81、945 |
| 装备 | 正常带出，带出即绑定 | R-133 |
| 时间 | 内外 4:1，试炼内 4 天 ≈ 现实 1 天 | R-060 |
| 倒计时 | 结束前 30 秒开始提示 | 1124 |
| 死亡 | 不回归 | R-231 |
| 奖励 | 回归瞬间结算并锁定归属 | 466、995 |
| 追杀 | S 级技能持有者回归后仍会被追杀 | 803 |

**这条最容易被写漏**：回归不是"满血复活"。重伤就是重伤，装备坏了就是坏了，回到现实还得自己掏钱修。

### 5.4 回归后的现实侧

- 官方登记：基因针剂类带出须实名登记（第 137 章）。
- 战利品变现：野市、公会、财团三条渠道（原著样本为变卖与拍卖）。
- 队伍解散：团队试炼结束即解散，下次重新标识。
- 配额刷新：按月计算，不按场次。

## 六、关卡模板：落点与回归字段

### 6.1 追加字段

| 字段 | 取值 | 说明 |
|---|---|---|
| 入场方式 | 系统投放 / 固定入口 / 随地处 | 决定开篇第一段写什么 |
| 落点规则 | 固定 / 随机 / 队伍分散 / 限时自选 | 决定队伍是否要先集合 |
| 原点 | 有 / 无 | 有原点则失败可重来 |
| 落点周边 | 列出 2–4 个可见设施 | 塔、城、关隘、补给点、矿窟 |
| 场内传送点 | 数量 + 使用限制 | 次数、冷却、是否收费 |
| 回归地点 | 预设安全点 / 十公里环带 | 默认环带；安全点需入场前登记，只存坐标 |
| 回归倒计时 | 30 秒 / 即刻 / 无 | 给交易与捡漏留窗口 |
| 回归状态 | 伤势保留 / 装备带出 / 绑定 | 写清楚哪些不带回 |

### 6.2 三种常用开局写法

**写法 A：系统投放 + 队伍分散**
落地先写环境，再写队友不在身边，第一目标是集合。适合团队场。

**写法 B：固定入口 + 原点**
落地即原点，周围有塔与补给点，失败可回原点重来。适合探索、采集场。

**写法 C：随地处捏碎 + 即刻开战**
没有缓冲，落地即接敌。适合死战、强制试炼卡。

### 6.3 回归段落写法

- 先写倒计时，再写光/失重/耳鸣，最后写落脚点。
- 落脚点必须具体：试炼厅地面、回收点、仓库门口——不要写"回到了现实"。
- 回归后第一件事是清点，不是感慨：装备、卡、伤、钱。
- 如果带伤，第一段就要写疼，不要等到下一章。

## 七、写作校验清单

- [ ] 入场方式是否明确（投放/入口/随地处）
- [ ] 落点是否写了周围至少两个可见设施
- [ ] 队伍是否按规则集合或被打散
- [ ] 原点机制是否交代（若本关有）
- [ ] 传送次数与限制是否写明
- [ ] 回归是否有 30 秒倒计时
- [ ] 回归地点是否具体到坐标或设施
- [ ] 回归后是否保留伤势
- [ ] 带出物品是否写明绑定
- [ ] 死亡是否没有回归

## 九、待拍板

1. **回归落点**：已拍板。预设安全点或十公里环带，默认环带；首试由系统回收到投放阵列，走另一套；私路固定两个坐标。
2. **场内原点是否保留**：保留。失败回原点重来，只作场内锚点，不是回归落点；静默环星不设。
3. **回归伤势是否保留**：建议保留，与"死亡即真死"形成一致的代价体系。
4. **队伍分散是否启用**：主角独行，卷一不用；团队场留作后续。
5. **周边设施密度**：建议每场只写 2–3 个，写多了会变成地图说明书。

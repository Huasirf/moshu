## 一、一句话概括

**旧口径**：入场＝投放。人把卡放到投放台（或立柱凹槽）上，系统投放；前面还有准入资格、名单、配额、复检、高危标记、手背印记。

**新口径**：入场＝买投候室门票取号 → 刷身份卡进单人投候室 → 关门后持卡、意念绑定、**在手心激活**。投候室只负责保密，系统内部只记「入场档位」。

## 二、入口流程：以后只有这一种写法（三拍）

| 拍 | 动作 | 谁做 | 明确不能写成 |
|---|---|---|---|
| 1 | 在窗口买投候室**门票**，拿**场次号** | 本人 | 资格审批、准入名单、配额没满、内部名额 |
| 2 | 刷**身份卡**开门，进**单人投候室**，门锁死 | 本人 | 七色门、颜色分区、安检、复检、人工复核 |
| 3 | **持卡**、**意念绑定**、**在手心激活**（卡身化开） | 本人 | 放上投放台、塞进凹槽、按按钮、门外中止 |

要点：
- 全程不需要任何设备，**激活是手持卡完成**。
- 投候室只有门、灯、面板；没有投放台、没有摄像头、没有急停装置。
- 门外最多看到门缝光，**不能干预**。

## 四、保留但重新定义的四件事

### 1. 门票
一张门票＝一个场次号＝一间投候室的使用许可。**门票不是准入资格**，也不决定用哪一色卡。

### 2. 投候室
一人一间，门锁死、隔音、无窗，**只用于保密**：门一关，外面的人不知道里面用的是哪一色卡。
它不是考场、不是传送舱、不是检测间。

### 3. 试炼厅职能（保留）
发卡（成年礼）、配额、收购、配给、出售、产出交验。
**不办**装备、药品、工具买卖；没有投放相关窗口或设施。

### 4. 携带物（两套规则，别混）

| 场次类型 | 能带什么 |
|---|---|
| 公共试炼（用试炼卡进场的场次） | **只认槽位**：3 件装备 + 1 张道具卡 + 1 个特殊饰品位。背包、水壶、干粮、药品、工具、绳索、现金、通讯设备一律在入口剥离 |
| 私人远征（返界锚私路） | 可带食物、饮水、药品、工具 |

写公共试炼时，食物饮水只能在**厅外**交代一次（寄存、卖掉、换成食物卡/饮水卡），不许跟人进门。

## 五、卡与颜色（这部分没动，别改坏）

- 七色：白 / 黄 / 蓝 / 红 / 紫 / 金 / 黑；单人全色，团队只有白 / 紫 / 金。
- 颜色只代表难度与奖励档，**不锁人物等阶**；白、黄无门槛。
- **同色通关 5 次 = 卡源解锁下一色**（黄5→蓝5→红5→紫5→金5）；黑卡例外，紫5或金5任一满足。
- 卡源解锁**不是入场门槛**：没解锁也可以持有该色卡，进场只看手里那张卡。
- 生存场最低**黄色卡**（只指卡色，不是资格）。
- **黑卡**＝最高档正式卡，可买卖；**黑档**只指系统字段「入场档位：黑（封闭场）」，两者不能混用。
- 试炼卡激活即消耗；返还写「一张 X 色试炼卡」。

## 十、重新调整章纲时要注意什么（重点）

1. **入场只有三拍**：买票取号 → 进投候室 → 手心激活。不要加“登记、报名、读卡、核验、复检、盖章”任何一拍。
2. **门票不是资格**。写“买不到票”“票卖完了”可以；写“准入资格不够”“配额没满所以不让进”不行。
3. **投候室只负责保密**。不要在室内写机关、扫描、摄像头、暂停按钮、传送到别处的装置。
4. **激活必须在掌心**。写“放在台面上”“塞进凹槽”“面板亮起把卡吞下去”都是旧设定。
5. **携带物分两套**：公共试炼只认 3 装备＋1 道具卡＋1 饰品；私人远征才可带食物水药品工具。别让主角揣着干粮进水壶进场。
6. **颜色只属于卡**。装备写 F–S 级；不要写“白装护腕”“黄色装备”，也不要写“他已经是黄阶”。
7. **卡源 ≠ 入场门槛**。同色 5 次只决定能不能买/领下一色卡；没解锁也能拿该色卡进场。
8. **伤势必须有来源**。只有战斗、试炼遇袭、现实埋伏、章纲指定致伤事件才写伤口；砸废铁、搬货、切菜、磕碰、摔倒、门夹一律不写，“旧伤＋布条”也不写。没有致伤事件时伤口数必须为 0。
9. **系统提示独立成段**，以【系统】开头或整段方括号字段，不进人物对白、不加引号。
10. **不要整段科普规则**。入场、卡、价格只通过动作、单据、系统提示透露，一段最多两句。
11. **价格句要带地点介词**：写“在东区黑市口，这盒东西能换他半个月工资”，不要写“这个区，这盒东西值他半个月工资”。
12. **开篇不写流水账**。只有全书第一章需要“世界→时代→地点→事件窗口→人物”，其余章节第一段必须直接承接上一章结尾动作。
13. **黑卡与黑档分开**。黑卡是正式卡；“黑档”只出现在他自己的面板和系统内部字段，别写成“黑色试炼卡”“黑色公共场”“第八色”。
14. **章末钩子与章纲表要对齐**。改流程后，第3章应直接从接驳井开场，承接“观测层尚未关闭”，不再重复第2章末尾的报错。
